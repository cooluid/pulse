# 2026-09-21

## 界面主题问题的根因诊断（待用户选路线）

用户反馈：界面主题改了 N 版都不理想，AI 每轮只改样式不改布局，主题名约束发挥，产出全是细线条，没有付费欲望。

排查结论：

1. **根因是架构，不是美术。** `PulseVisualTheme`（pulse/Data/AppSettings.swift）在代码里唯一能力是提供 `PulseThemePalette` 的 9 个颜色槽。布局差异只能靠散落的 `if theme == .xxx` / `switch theme` 硬编码，分布在 `PulseTodayPage`、`PulseCheckInFace`、`PulsePrimaryNavigation`、`PulseAppHeader`、`PulseScreenBackground`、`SettingsView`、`EnhancementStoreView` 等 6+ 文件。改颜色是最低成本路径，所以每轮迭代必然只出"换漆"。
2. **名字不是根因，是放大器。** 主题名是视觉隐喻承诺（sunlitDay / moonTide），但布局层没有可调参数，隐喻只能用装饰兑现 → `PulseStampOutline`、`PulsePageFold`、`PulseTideTrace`、`PulseSeedShape`、棱镜刻度线即"垃圾线条"。改名史（Tidal Breath → Tide Archive → Sunlit Day，Fault Almanac 被移除）证明改名无效。
3. **付费结构反了。** 免费主题 `editorialJournal` 是设计最完整的一套；付费主题只是同一页加装饰。价格必须来自结构差异而非装饰密度。
4. **`PulseTodayPage` 的泛型注入（checkIn/journal/media）已经把"事实"原子化了，可复用。** 但它把"编排"也写死了，主题只能做 `padding(.top, theme == .moonTide ? 96 : 0)` 这类数字魔法微调。
5. 测试现状：`pulseTests/ThemeExperienceContractTests.swift` 只锁权益/免费主题归属，未锁几何与颜色（符合 AGENTS.md 边界）。`PulseDesignSystem.swift` 无测试锁定。

候选路线（未定）：

- A（主推）：编排契约化。事实层保持唯一实现，编排抽成协议，每主题一个实现文件；`switch theme` 消失，改为多态。新增/重画主题不动其他主题与事实层。
- B：参数化 Recipe 结构体。风险是参数化陷阱，加了参数仍是同一页，不建议做主方案。
- C：命名滞后。先做体验后命名；名字从视觉隐喻改为使用场景/人格。需与 A 同时做，单独做等于再次改名。

状态：等待用户选择路线，尚未改代码。

## 实施结果（路线 A + C，同日完成）

用户选择路线 A + C，要求风格"融合/流体"，明确不要平庸。

1. **编排契约**：`PulseTodayPage` 拆为「事实容器 `PulseTodayFacts` + 分派器 + `legacyComposition`」。新主题走 `PulseImmersionTodayPage` 独立文件，旧主题路径原样保留（零回归）。对外接口未变，`TodayView` / `PulseVisualThemeSpecimen` 无需改动。未来重做其他主题只需逐个搬出 legacy。
2. **新增主题 `immersion`（中文「沉浸」）**，名字描述体验而非视觉隐喻，避免重蹈"按名字画线条"。强制深色（与 moonTide 同策略），青绿 accent `#43E0B8`，底色 `#080B10`。
   - 结构差异：巨大日号（176pt black）右对齐、底部渐隐，作为页面唯一强音；签到面是全宽 104 高、圆角 38 的有机面（未签到 = accent 实色 + 辉光，已签到 = accentSoft 静默态）；周流用 Canvas 画高低起伏的连续带取代 7 个胶囊。全程无卡片、无 1px 装饰线。
3. 令牌：9 个 `immersion*` 颜色写入 `design/brand-tokens.json` 与 `build_brand_assets.py` 的 `COLOR_ASSETS`，生成 9 个 colorset。
4. 测试：`ThemeExperienceContractTests` 更新期望并新增 immersion 令牌断言；新增 UI 测试 `testImmersionThemeRendersSurfacePickerAndCheckIn`（切主题 + 截图）。
5. 验证：编译通过；203 个单元测试通过；既有主题两个关键 UI 测试通过。
