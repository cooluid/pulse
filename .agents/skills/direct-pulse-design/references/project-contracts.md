# Pulse 项目合同与证据路由

## 必读

- `RELEASE_SCOPE_1_1.md`：范围
- `IMPLEMENTATION_STATUS.md`：工程与证据状态
- `design/BRAND_SPEC.md`：只说明外观工程和人工验收边界，不提供设计方向
- 目标页的 SwiftUI / 字符串 / 测试

## 路由

| 问题 | 权威 |
| --- | --- |
| 签到、日期、统计、删除、导入 | `DOMAIN_CONTRACT.md` |
| 产品任务 | `PRODUCT_REQUIREMENTS.md` |
| 文案用词 | `CONTENT_DESIGN_SPEC.md` + String Catalog |
| 仪式时序 | `PULSE_RITUAL_CONTRACT.md` |
| Widget 产品/store | Widget 相关合同中的**事实**条款 |
| **任何页面的外观** | 当前任务 + 当前实现 + 人工判断；无长期文档权威 |

美术与事实冲突 → 改正事实表达，不禁画法。不要创建参考板、反参考、页面映射或设计意图合同。
