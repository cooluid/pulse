# Pulse 项目合同与证据路由

## 必读

- `RELEASE_SCOPE_1_1.md`：范围
- `IMPLEMENTATION_STATUS.md`：证据状态（不是视觉锁）
- `design/brand-tokens.json`：颜色工程
- `design/BRAND_SPEC.md`：**全产品美术自由**；只硬锁事实 / 无障碍 / 权益 / 工程入口
- 目标页的 SwiftUI / 字符串 / 测试

## 路由

| 问题 | 权威 |
| --- | --- |
| 签到、日期、统计、删除、导入 | `DOMAIN_CONTRACT.md` |
| 产品任务 | `PRODUCT_REQUIREMENTS.md` |
| 文案用词 | `CONTENT_DESIGN_SPEC.md` + String Catalog |
| 仪式时序 | `PULSE_RITUAL_CONTRACT.md` |
| Widget 产品/store | Widget 相关合同中的**事实**条款 |
| **任何页面的外观** | 代码 + 人工截图；文档不否决画法 |

美术与事实冲突 → 改正事实表达，不禁画法。
