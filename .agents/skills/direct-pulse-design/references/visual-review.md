# Pulse 视觉与界面系统审阅

只在审阅视觉方向、构图、字体、颜色、组件外观、AppIcon 或商店图时读取。先读取 `../../../../design/BRAND_SPEC.md` 与真实消费者，不从一张截图反推整个设计合同。

## 三秒第一读

- 先判断用户是否立即看到当前日期/页面、今日状态和唯一主动作；品牌装饰不得抢走任务焦点。
- 今日页应是一体化脉冲场，不把日期、周轨迹、签到和节奏拆成重复卡片。
- 主承诺是节奏语境，不是压过日期与签到的第二个页面标题。
- 历史页先让用户理解月份、当前统计和可交互日期，再提供详情与删除。
- 设置页保留系统 Form/List 的可预期性，不为“品牌感”重画标准开关、选择器、确认和文档入口。

## 构图与布局

- 在 iPhone 紧凑宽度检查中轴、上下节奏、底栏避让与可滚动末端，不用裁剪过的宣传图证明布局。
- 在 iPad 常规宽度检查真正的双区关系、视觉重心和信息密度；居中放大 iPhone 单列不是 iPad 设计。
- 检查横竖屏、分屏、最短高度、最长内容和键盘出现后的结构稳定性。
- 装饰场线、阴影和光环不能穿过正文、盖住交互、进入底栏或制造虚假层级。
- 页面不通过散落负间距、设备特判或日期位数特判修补裁切；先修正式几何和内容布局。

## 字体、数字与图标

- 使用系统字体和文本样式；只有明确的展示数字可以使用集中令牌控制的大字号。
- 日期数字保留自然字距与完整字形边界；用真实 1–31、中文/英文月份和不同 Locale 检查。
- 统计数字使用等宽数字时，检查基线、单位和最大合法值，不让数字变化推动周围布局跳动。
- SF Symbols 和品牌开放日环各守职责；不要把通用系统图标伪装成品牌资产，也不要为普通设置动作另造图标体系。
- 文本和图标必须在真实 Dynamic Type 与渲染倍率下检查，不用缩小宣传图掩盖断行和细线消失。

## 颜色、明度与材质

- 只按语义角色判断 `background / surface / grass / action / ink / secondary / field / separator / shadow`，不要把具体 RGB 复制到建议里。
- 在浅色和深色分别确认：待执行 `action` 低于完成 `grass` 的生长亮度；完成态同时具有形状/图标/文字语义。
- 检查高对比度、降低透明度与灰阶理解；半透明材质失效时仍应保持层级和边界。
- 阴影只服务悬浮导航或主操作；同心场是低强调环境，不成为发光特效。
- 拒绝渐变、霓虹、多彩统计、层层毛玻璃、泛滥卡片和火焰/勋章等焦虑或奖励化表达。

## 品牌一致性

- 品牌性来自开放日环、草叶生长、同心节奏、克制措辞和可靠状态，不来自额外插画或伪书法。
- 新组件必须复用正式字体、间距、圆角、线宽、颜色和动效令牌；局部漂亮但建立第二套系统应判为 MAJOR。
- 视觉建议必须解释它如何强化“可靠、私密、没有压力”；与这三项冲突的流行风格不能因为“更吸睛”而通过。
- 不把 AppIcon、App 内主印和 SF Symbol 做成三个相互竞争的品牌标志。

## AppIcon 与商店素材

- AppIcon 使用正式生成链与开放日环真源；检查 Default、Dark、Tinted，不手工修一张派生 PNG。
- 同时检查 29、40、60、180 和 1024 尺寸的识别、线宽与视觉居中；大图漂亮不能替代小尺寸成立。
- 商店图必须来自正式 App 和真实范围，不展示未实现的 Widget、Watch、Live Activity、云同步或图片能力。
- 商店文案、设备显示名和截图语言遵循中文“一日一印”、英文/其他语言“Pulse”的身份合同。

## 建议的静态证据矩阵

至少根据改动范围覆盖：

- iPhone：待签到、已签到、保存失败、历史当前月、历史过去月、设置、确认/Sheet。
- iPad：今日双区、历史双区，至少一组竖屏与横屏/分屏。
- 外观：浅色、深色；涉及材质时增加降低透明度/高对比度。
- 字号：默认、至少一种较大常规字号、Accessibility 最大字号。
- 语言：简体中文、English，并使用真实长主承诺/说明与最大统计数值。

只覆盖一个理想状态时最高判 `INTERFACE CANDIDATE`。
