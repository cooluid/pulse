# Pulse 视觉审阅（美术不锁死）

先读实现与截图，**不要**用旧视觉合同清单否决探索。

## 硬门槛（非美术）

- 用户能否立刻找到日期/页面、今日状态、唯一主动作
- 状态是否对应权威事实（不发明第二份签到/历史）
- Dynamic Type / VoiceOver / 对比：信息仍可完成，不单靠一种感官通道
- 设置等系统控件保持平台可预期语义

## 软门槛（美术）

- 好不好看、像不像某材质、渐变/红霞/装饰是否加分：**人工说了算**
- 给建议、给对比方案；**不写**「禁止卡片/渐变/毛玻璃/伪书法」之类效果黑名单
- 改 Widget 外观不必先改长文档；原型 HTML 只是草稿纸

## 证据

缺真机/主屏截图时最高 `CANDIDATE`。App 画廊不能单独写成 Home Screen GO。
