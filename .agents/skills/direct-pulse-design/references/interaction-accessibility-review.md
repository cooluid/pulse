# Pulse UI/UX 与可访问性审阅

只在审阅信息架构、流程、控件、导航、错误、双语、Dynamic Type、VoiceOver 或隐私时读取。

## 任务

写出目标、起点、成功出口和失败恢复：首次确认一件事、今日签到一次并确认已保存、看七日/月历/统计、打开或删除记录、改设置、导出/恢复/清除并理解后果。

任何建议如果增加步骤、重复解释或引入新概念，必须证明它降低了错误。

## 状态

覆盖 `loading / ready / saving / success / empty / disabled / error / confirmation`。
保存短于阈值不闪加载器；失败保留输入和重试；已签到、未来、开始前、漏签、待签到可区分且不只靠颜色。
禁用说明当前不可操作。页面重建、回前台和重启从权威事实恢复。

## 导航与控件

主导航只有今日与记录。设置是次级层，进入时根内容离开辅助功能树。
用 Button、Picker、Toggle、Form/List、Sheet、confirmationDialog。
破坏性操作看来源、目标和取消。点击目标至少 44×44 pt。

## Dynamic Type 与适配

从默认到 Accessibility 最大字号走完整流程。主动作与底栏必须可操作。固定底栏不得挡住最后一项。4–12 字符名称、160 字说明、长时区名、English 和本地化日期都要看。键盘与焦点链走系统语义。

## VoiceOver

阅读顺序：页面身份 → 当前状态 → 主动作 → 次级信息。
日期、签到状态、连续天数、日历状态、按钮行为和禁用原因要有标签/值/提示/traits。
纯装饰移出辅助功能树。已签到日用真实 Button；月份切换提供可发现的辅助功能动作。
标识符存在和 UI 测试通过不证明朗读自然，主流程要人工听一遍。

## 系统辅助设置

- Reduce Motion：保留状态理解，去掉缩放、回弹、扩散和循环呼吸。
- 降低透明度：导航和表面仍有明确边界。
- 增强对比度/灰阶：状态仍由形状、图标或文字成立。
- 深色模式：待执行与完成可区分，细线仍在，系统 Form 仍可用。
