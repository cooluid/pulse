# 外观工程

运行时外观由当前 SwiftUI、Asset Catalog 和 Renderer 实现。
`design/brand-tokens.json` 与 `scripts/build_brand_assets.py` 是颜色和图标资产的生成入口，可按设计任务增删、改名或重建。
用户可见文字只改 String Catalog。中文名「一日一印」，英文名 Pulse。

签到、日期、统计、记事、照片、删除、恢复、价格和权益必须与领域/产品合同一致。
状态不能只靠颜色。VoiceOver、Dynamic Type、Reduce Motion、提高对比度和系统托管表面必须可用。

外观是否通过：看完整页面和真机。
