# 一日一印（Pulse）1.1 品牌与界面规范

冻结日期：2026-08-13
决策来源：“草野脉冲”根页面 × “状态式悬浮底栏”主导航 × 独立高阶权益页
适用范围：一日一印（Pulse）1.1 iPhone / iPad 产品界面、今日入镜、基础 Widget、AppIcon 与商店素材
完整度：品牌名称、颜色令牌、界面系统、主导航、购买页与正式 AppIcon 已冻结

## 0. 品牌名称

- 简体中文正式名称：一日一印。
- 英文及其他语言正式名称：Pulse。
- 简体中文设备、中文界面和中文商店素材统一使用“一日一印”，不得混用 Pulse 作为中文显示名称。
- Xcode target、Swift 类型、数据协议和 Bundle ID 保持稳定的工程名 Pulse，不产生第二套技术身份。

## 1. 品牌立场

一日一印是一个可靠、私密、没有压力的每日记录工具。视觉记忆点来自“草叶生长 + 日环留下印记”：深草绿表达尚待完成的行动，鲜草绿表达已经发生的生长，同心脉冲场表达每天一次的轻量仪式。

关键词：草野、呼吸、清晰、克制、细腻、可靠、私密。

今日入镜增加“显影”而不是建立第二套相机品牌：照片是内容层，草色开放日环、低干扰暗场、真实时间与“今日入镜”措辞负责 Pulse 身份。禁止套用相机取景器仿真、胶片滤镜商城、霓虹渐变或自拍美颜语言。

## 2. 唯一视觉真源

所有正式颜色只在 `design/brand-tokens.json` 定义一次。`scripts/build_brand_assets.py` 从该文件和唯一开放日环蒙版生成运行时 Color Set、AccentColor、AppIcon 三种外观与 `PulseMark`；SwiftUI 只按语义名称消费生成资产。Widget 的小尺寸开放日环由同一代码原语按容器几何绘制，不归档第二份位图标记。

不得在 Swift、Asset Catalog、AppIcon 脚本或设计文档中复制另一份颜色值。新增或修改颜色必须先修改品牌令牌，再重新生成并执行：

```sh
python3 scripts/build_brand_assets.py
python3 scripts/build_brand_assets.py --check
```

正式语义角色：

- `background`：页面底色。
- `surface`：悬浮导航、今日入镜与系统表单表面。
- `grass` / `grassForeground`：完成态、已完成导航与其前景。
- `action` / `actionForeground`：待签到主动作与其前景。
- `ink` / `secondary`：主次文字。
- `field`：低强调同心脉冲场。
- `separator` / `shadow`：结构边界与悬浮层级。

浅色与深色必须分别使用令牌中明确的外观值；完成状态还必须同时出现勾形、完成文案或可访问性标签，不能只靠颜色表达。
所有 prominent 待执行动作必须显式同时使用 `action` 背景与 `actionForeground` 前景，不依赖系统从 tint 推断文字颜色；必须在动作真实色场中验收对比度。

## 3. 字体与数字

- 中文、英文、数字和控件统一使用 Apple 系统字体与 Dynamic Type。
- 今日日期使用系统 Display 字形、轻字重与 `monospacedDigit`；月份和统计数字使用系统粗字重，形成安静而清楚的张弛对比。
- 页面标题、正文、说明和标签使用系统文本样式，不固定正文尺寸。
- 不引入第三方字体，不产生字体授权、下载、回退和多语言维护链路。

## 4. 今日页：草野脉冲

- 年月、日号、主承诺、签到动作、最近七天与节奏摘要必须属于同一个脉冲场，不拆成重复卡片。
- 最近七天只保留一条周轨迹，不得再出现第二份“最近 7 天”信息。
- 周轨迹位于签到状态之后、节奏摘要之前，不得与签到圆叠压，也不得沉到主导航之后破坏信息关系。
- 周轨迹的七个节点必须共用同一圆径和文字基线；今天待签到只用 `grass` 空心描边表达，已签到使用 `grass` 填充，禁止放大今天节点导致星期文字错位。
- 大号日期使用系统数字的自然字距并保留完整字形边界；不能用日期特判、负字距或额外补白修补两位数裁切。
- 待签到与完成态共用同一中轴日期结构：年月与星期合并为顶端信息行，日号独占中轴，不重复显示“今天 / TODAY”。
- 常规 Dynamic Type 下，待签到使用深草绿实心圆与空心印记，并在圆内显示“今日待签到”；权威提交成功后切换为鲜草绿完成印，并只在圆内显示“实际时间 · 已留印”。
- 深浅色外观都必须保持 `action` 待执行态低于 `grass` 完成态的生长亮度；状态变化不能只替换文字。深色模式不得把待执行动作做得比完成印更亮。
- Accessibility Dynamic Type 下，主动作必须改为可纵向扩展的通栏胶囊，禁止把放大文字压进固定直径圆形。
- 完成态不显示“写入本机后完成”或圆外“已于某时写入本机”等重复说明。
- 页面进入且今日待签到时，主动作外环只允许完成一次有限呼吸；按压、持久化成功与照片写入只提供一次性状态反馈。页面失活、已签到或开启 Reduce Motion 时不播放呼吸，且 Reduce Motion 取消位移、缩放和扩散。
- 常态动感由背景脉冲场承担：18 秒一轮的低振幅呼吸、最多 7 pt 的水平漂移、两条 1 pt 流线与今日页三层低透明潮面共同构成环境层，并以最高 12 fps 的低频时间轴更新。潮面只能形成可察觉但不抢正文的明度起伏，不能模拟液体物理或进度。它只在 App 位于前台且 Reduce Motion 关闭时驱动；进入后台、失活或开启 Reduce Motion 后立即静止。环境层不得改变布局、阻塞触控、制造加载语义或与签到反馈争夺注意力。
- 本地写入短于 250 ms 时不闪现加载器；超过阈值后才显示保存进度。写入成功后先完成主印，再轻量更新周轨迹与连续天数，禁止所有信息在同一帧生硬跳变。
- 连续天数是次级节奏反馈，不使用火焰、积分、勋章或制造断签焦虑的奖励表达。
- 今日页在日号与签到主动作之间投影主承诺名称，作为“今天守住 / Today’s Commitment”的轻量只读语境；名称只读取正式 `Habit` 真源，不保存页面副本。可选备注只在首次确认与设置编辑页出现。
- 主承诺提示不使用卡片、边框、阴影、材质、伪按钮或编辑入口，也不进入签到圆内部，不与日期争夺第一视觉。
- 日期英雄区与签到主动作之间使用正式正间距，不再以负间距让签到圆覆盖英雄区。常规字号下长名称使用有限行数；Accessibility 字号允许自然换行和滚动。内容增长只能让后续内容顺序下移，不得重叠、缩字或按设备特判。
- 周轨迹之后只保留一行居中的连续状态：连续为零时使用“从今天开始”，大于零时使用完整的“连续 N 天”。它是无交互的次级结论，禁止左右分栏、边框、胶囊、卡片、阴影、材质背景和伪按钮命中区。
- iPad 常规字号使用正式双区构图：日期与主动作在左，周轨迹与节奏反馈在右；不得把 iPhone 单列整体居中后留下无意义的大面积空白。Accessibility 字号仍使用可滚动单列，保证阅读顺序稳定。
- 单击开放日环只签到；长按 0.45 秒表示“签到并拍照”。长按成立后先执行同一权威签到事务，只有持久化成功才请求相机；相机取消、拒绝或失败不回滚已经完成的签到。
- VoiceOver 必须保留标准“签到”按钮动作，并提供独立命名的“签到并拍照”辅助功能动作；不得要求辅助功能用户模拟长按。
- 今日入镜不是第三个底部控制区。签到成功后，它只作为完成印右下方的 44 pt 伴生副动作出现：无照片时显示相机图形与“入镜”，已有照片时显示真实圆形缩略影与“查看入镜”。入口必须在周轨迹之前结束，不得靠近或模仿主导航。
- 真实照片、重拍与删除只进入独立详情 Sheet；今日与历史必须复用同一个照片详情骨架、导航栏、照片几何和右上管理菜单，只按上下文投影不同动作。根页不显示全宽媒体卡、深色通栏拍照按钮或第二块底部容器。

## 5. 主导航：状态式悬浮底栏

- 根界面只使用 `PulsePrimaryNavigation`，不保留系统 `TabView` 或旧 TabBar 的兼容分支。
- 今日项显示真实日号、页面名与选中态的“待留下印记 / 今天已完成”；记录项显示当前月号、页面名与选中态的“查看日历”。
- 记录项进入月历与统计。选中项使用 `grass` 填充，未选中项保持低强调表面。
- 两个入口始终等宽；选中背景在两项之间短距离平移，不通过宽度挤压追逐焦点。悬浮容器只使用一次系统材质、语义 surface 覆盖、单线边界和单层阴影。
- Accessibility Dynamic Type 下保持等宽、隐藏副标题并允许标签纵向扩展；不得裁切数字与页面名。
- 所有可滚动根内容必须使用底栏真实测量高度作为末端清空区，滚动到末尾后最后一项完整位于底栏之上；不得只在 Accessibility 字号处理，也不得按设备硬编码补白。
- 根内容同步做一次性短距离淡入位移；开启 Reduce Motion 时内容和选中背景都立即切换。
- 整个导航悬浮于页面底部并尊重安全区，所有交互目标不小于 44 × 44 pt。
- 两个根 `NavigationStack` 保持各自的页面导航状态；不可见根页不得响应触控或辅助功能焦点。
- 设置属于根页面之上的次级导航层；进入设置时隐藏主导航并释放底部安全区，返回根页面后恢复，禁止两层导航同时占据屏幕。

## 5A. Home Screen Widget：七种仪式物件

构图方向真源是 [`docs/prototypes/widget-ritual-objects/`](../docs/prototypes/widget-ritual-objects/) 的正式清单：落印、叠印、数影、手札、静场、来路、潮痕；潮痕的像素构图真源是 [`01-tide-mark/pulse-widget-tide-mark.html`](../docs/prototypes/widget-style-experiments/01-tide-mark/pulse-widget-tide-mark.html)。正式 `PulseWidgetHomeRenderer` 与逐实例枚举只实现这七式；旧五式「呼吸环 / 深景 / 静序 / 七日谱」以及任何「状态—日期—承诺—七日—按钮」仪表盘骨架都不再编译或作为视觉依据。

- Home Screen 小号与中号提供七种物件构图。落印是唯一免费构图；叠印、数影、手札、静场、来路、潮痕由同一个高阶权益 entitlement 解锁。构图类型由 WidgetKit 逐实例配置持有，App Group 不保存全局样式；同一主屏可同时放置不同构图。
- 七式是七种能认出来的物件，不是背景皮肤。斜眼看去剪影必须不同：一枚印、一叠印、一个溢出的日子、一封短笺、一片静场、一条来路、一段天岸潮线。不得用颜色场、圆形装饰或位置微调伪装成新构图。静场不是手札的放大版，潮痕也不是数影加一层水纹。
- 「落印」：大开口日环就是物件。浅底、淡残影、洗色环带加细开口，内核几乎透明；待办在环心写「留印」。日期用 `08 / 13` 一类说明写法，不做 `13/8`，也不占半屏——半屏日号留给数影。中号日号保持说明级，环继续占左。完成时环闭合、内核实心、勾压在核上。
- 「叠印」：同一枚印压在最多三层错位纸边上，纸叠铺满画布。今天这一枚在最上面。日号是说明，不是第二主角；半屏大数字留给数影。漏签不占一层。
- 「数影」：日号用粗体半透明剪影占住画面。小号潮面只铺下沿，中号潮面横贯。月份贴上沿，承诺在右上。右下角保留一枚小开口日环作今日示意；整张卡是唯一签到命中面，印不是第二块按钮。完成时环闭合打勾，日号仍是主角。不重复七日轨、次数汇总或第二个日期。
- 「手札」：一张浅色信纸。右上蜡封是今天，下沿是一串等大邮戳日环。它是信纸的附言，不是来路，也不是旧七日谱看板。漏签空心，已留下实心，今天开口；完成时今天邮戳闭合，蜡封打勾。
- 「静场」：墙上的海报。残影从右下角印的圆心扩开，字在场上，印在原点。今日印与其他式同一草叶色开口日环，「留印」用深绿；完成时环闭合打勾。不为了「显得完整」补回七日轨，也不能把脉冲场挪成角落装饰。
- 「来路」：走过来的一串印，不是折线加点的健康图。过去六日由远到近、由小到大；漏签空心，已留下实心。今天是开口日环，环心是今日日号。完成时环闭合，勾只作小记。不写「近七日 N 次」。
- 「潮痕」：先认天际线，再认潮。上天空与地平线、下潮唇与一尾水下剪影鱼，开放日环停在岸上且环心不写日号；完成时潮线上移贴近日环并闭环。禁止百分比水位、鱼群、气象图标和数影式大日号。潮痕唯一允许使用由 `widgetSky` / `widgetSkyMiddle` / `surface` 组成的单轴语义渐变；这不是其他构图引入任意 RGB 渐变的许可。
- 七式消费同一个不可变 `PulseWidgetSnapshot`，但只投影各自完成任务所需的事实。日期、主承诺、今日状态或七日信息在同一构图中不得用文字、节点与统计重复表达。照片、备注、连续天数和 4/7 分数不进入 Widget。
- 小号与中号必须使用明确的响应尺寸参数，不把小号等比拉宽，也不把中号当成松散小号；以 `1 / 10 / 11 / 31` 日号、长承诺、中英文和七日全状态组合检查密度、截断与完整字形边界。
- 日期使用系统圆角字与等宽数字，不使用负字距、日期位数特判、硬编码假日期或缩放整张布局补救裁切。半屏数字允许低对比，但完整字形必须始终在安全边界内。
- 七日状态中，已签到为大实心，漏签为小实心低强调，项目开始前为小空心，今天待签到为大空心强调；状态不能只依赖颜色。手札邮戳可在已留下节点内增加勾形；来路的今日勾不得盖住日号。
- Home Screen 未签到时，系统分配的完整可见区域是同一个单向签到 `Button`；完成态整块静态且不可撤销。禁止只让日印或某个日期节点可点，也禁止一张 Widget 出现多个等价签到入口。
- Home Screen 与 Accessory 共用代码原生日环：312° 环段、9% 线宽、圆润端点；Home Screen 未签到使用 `action`，完成后使用 `grass`，Accessory 交给系统单色或着色调色板。完成态由实心内核、勾形、状态文字和辅助功能标签共同表达。
- App 内构图画廊与 Widget Extension 必须编译同一份 `PulseWidgetHomeRenderer`；画廊只使用当前主承诺和当前七日事实生成的正式快照。禁止独立近似预览、硬编码日期、按索引伪造签到状态或在画廊提供不能配置已安装 Widget 的“已选择”状态。
- Home Screen 构图选择只存在于系统“编辑小组件”的 `WidgetConfigurationIntent`；无构图参数的 Lock Screen“节律汇印”是独立 Widget kind。Widget extension 在每次 snapshot/timeline 独立验证 entitlement；收费构图在权益未验证或撤销时必须明确显示“构图尚未解锁”，不得静默替换为落印，也不能读取 App 侧购买布尔副本。
- Home Screen 固定显示主承诺名称且只读取 `Habit` 真源；Lock Screen、StandBy 与 Always-On 不显示主承诺正文，任何 Widget 都不显示可选备注或媒体。
- Accessory 使用唯一“节律汇印”语法：圆形在今日开放环或完成印内部显示本地化当日纯数字；矩形左上显示今日短状态，过去六日节点上方显示真实日号并以连接线流向右侧唯一今日印记。不得把今天重复成第七个小节点。
- Accessory 待签到圆形与矩形的完整可见区域都是同一个单向签到 `Button`；完成态静态。矩形内部节点从辅助功能树隐藏，整块只朗读今日状态、过去六日结果与操作提示。
- Home Screen 全彩模式只使用品牌语义 Color Set；除潮痕已定义的单轴天空渐变外，禁止其他自绘渐变。系统着色或透明外观通过 `widgetRenderingMode` 分离主内容与强调内容。`containerBackground(for: .widget)` 保持可移除；禁止自绘毛玻璃、霓虹调色板、粗黑装饰线、emoji、随机旋转和不可预测裁切。
- 所有 Widget 都静态响应权威事实更新，不用 timeline 伪造连续动画。Reduce Motion、Accessory 与 Always-On 始终有完整静态等价表达。
- 共享 store 未就绪、身份未确认或快照损坏时显示明确“打开一日一印 / Open Pulse”或不可用状态，不能显示虚假待签到。App Group UserDefaults 只允许 `interface.language`，不存在 `widget.style` 旧路径。
- 七种物件的小号与中号，以及 Accessory Circular / Rectangular，必须分别在系统 Widget Gallery 与真实表面验收待签到、已签到、浅色、深色、accented、vibrant 和 Clear；App 内画廊、Preview、编译成功、HTML 实验室或资产尺寸检查不能替代运行证据。

## 5B. 独立高阶权益页

- 买断功能必须拥有独立页面，不得埋在设置分组内，不得使用弹窗假装商店页。
- 商店页的商品身份、价格、可购买状态与权益状态只读取 StoreKit；禁止硬编码价格、伪造折扣、倒计时或虚假稀缺性。
- `PulseEnhancementContract.currentCapabilities` 是当前已交付买断能力的唯一目录。商店页按目录投影权益，不在界面另存一份固定清单。
- 当前能力包括高级 Widget 构图与定时 Live Activity。未来能力只有在真实实现并加入能力目录后才能出现在购买页；同一永久权益可以持续增值，但不得预售尚未交付的功能。
- 页面以轻量权益身份区、草野构图真实预览、等宽满行权益卡和唯一购买动作为主；同组权益卡必须占满可用宽度并使用一致的最小高度，不能因文案长短呈现参差列宽。不得使用全大写海报口号、粗黑分隔线、倒计时、伪折扣或强压迫购买坞。购买、恢复、待批准、已解锁、不可用必须是明确状态。
- 设置只提供一个清晰的“高阶权益”入口和已解锁状态；Widget 样式选择进入独立样式画廊，收费样式被点击时明确进入高阶权益页。

## 6. 布局与组件

- 基础间距只使用 4 / 8 / 12 / 16 / 20 / 24 / 32。
- 页面水平边距：iPhone 20 pt；今日内容最大宽度 680 pt；历史内容最大宽度 760 pt；常规宽度双区内容最大宽度 1080 pt。
- 最小点击区域：44 × 44 pt。
- 今日与历史页面是无卡片的全屏脉冲场；根页面只允许主导航成为底部明确容器。今日入镜入口附着于完成印，真实媒体只在独立 Sheet 中使用容器。设置页保留系统 `Form` / `List` 交互语义，但背景与 Tint 必须接入品牌系统。
- 阴影只服务于必须浮起的照片或系统模态层级，禁止把全屏场域包进圆角卡片。
- 所有视觉常量集中在 `PulseDesignSystem.swift`，页面不得散落重复的颜色、间距、圆角或动效常量。
- 脉冲场按 compact / regular 宽度使用各自椭圆比例、环距、纵向位置与上下渐隐；装饰线不得遮挡正文、进入底栏或响应触控。
- Accessibility 字号下页头设置入口改用系统齿轮图形并保留完整可访问性标签，避免放大文字与品牌名争抢宽度。

## 7. 历史与设置

- 已签到日期：草绿完成印 + 勾形。
- 有影像日期：在签到状态之外叠加独立相机标记；仅影像日期仍可打开详情，但不得显示成已签到。
- 今天待签到：Action 描边 + 日期。
- 漏签：叶面底色 + 次级文字。
- 未来 / 习惯开始前：降低对比度但保持可读。
- 已签到日期必须使用真实 Button 语义打开详情，不用手势伪装按钮。
- 记录详情以日期、签到状态和真实照片为内容主体，不重复展示 App 标志，也不设置常驻动作坞。照片按照 `ImprintMedia` 的真实像素宽高比完整显示；禁止固定高度 `scaledToFill` 裁切、品牌色滤镜或为了填满容器拉伸照片。
- 详情导航栏尾侧只提供一个至少 44 pt 的系统管理菜单。今日菜单投影“重拍 / 删除照片”，历史菜单按事实投影“导出原图 / 删除照片 / 删除签到记录”；非破坏性动作在前，随后用系统分隔线隔开破坏性操作，缺失事实对应动作直接移除。标准与 Accessibility Dynamic Type 使用同一信息结构，不建立三栏、网格或缩字兼容分支。
- 删除照片与删除签到继续保持独立事务和独立二次确认。菜单项使用系统 destructive 角色，确认由同一个真实菜单源控件呈现；删除照片后保留签到与统计，删除签到后保留照片并在原位明确说明事实变化，两种事实都不存在时才关闭详情。
- 月份切换同时提供 44 pt 的上一月 / 下一月可见按钮、左右滑动和辅助功能动作；三种入口必须汇入同一月份状态变更函数。当前月禁用下一月，切换方向必须与日历位移动效一致。
- iPad 历史页使用“月份与统计 / 月历”双区构图；统计分隔线只取内容固有高度，不得随宽屏父容器拉成长空框。
- 设置、时区、导入导出、删除确认继续使用系统标准控件，避免品牌化破坏平台可预期行为。
- 今日入镜伴生入口使用 surface 胶囊与真实圆形缩略影，不对照片套品牌色滤镜；无影像时显示“入镜”，已有影像时显示“查看入镜”。进入详情后照片是第一主体，不把“重拍”塑造成主行动按钮；重拍与删除进入和历史一致的系统管理菜单，并保留完整文字、辅助功能标签与独立删除确认。
- 主题只提供跟随系统、浅色、深色三种模式并继续消费同一套语义 Color Set；不得复制页面或另建平行配色真源。
- 界面语言只提供跟随系统、English、简体中文；切换后 App 与 Widget 内容的日期、格式串、辅助功能标签和设置值必须消费同一 Locale，禁止中英混排残留。Widget Gallery 和 AppIntent 等系统托管静态元数据仍按 iOS 语言规则显示。
- 设置中的单项说明进入对应控件副标题，分组说明作为卡片内部的说明行，不使用脱离圆角卡片的悬空 footer。
- `confirmationDialog` 必须挂在发起操作的真实管理菜单上，让系统箭头指向可见来源。统一详情 Sheet 使用系统导航栏、关闭按钮与拖拽指示器；含照片状态默认使用 `.large`，只签到状态使用集中语义比例的紧凑 detent 并保留 `.large`，Accessibility 字号或紧凑高度直接使用 `.large`。禁止内容高度反馈循环、设备型号分支或散落 detent 数值。
- 设置入栈后根页不仅视觉隐藏，也必须从辅助功能树移除；返回后再恢复根内容和主导航。

## 8. AppIcon 合同

- 画布：1024 × 1024，不自行绘制系统圆角。
- 图形唯一真源：`design/app-icon-source/open-day-ring-mask.png`。
- 颜色唯一真源：`design/brand-tokens.json` 的 `icon` 与 `review` 角色。
- 生成器唯一入口：`scripts/build_brand_assets.py`；旧图标调色板与旧生成脚本不再存在。
- Default：品牌深草绿背景 + 白色开放日环。
- Dark：透明系统底 + 明亮草绿色开放日环；评审图以品牌暗色背景验证。
- Tinted：单一灰度遮罩，由系统应用用户色调。
- `design/app-icon-review.png` 必须由同一生成器确定性产出，展示三种外观与 29 / 40 / 60 / 180 px 小尺寸，不得手工维护或滞后于令牌。
- 不含文字、数字、拟物阴影、渐变、3D、照片或水印。
- 核心图形在 29、40、60、180 和 1024 尺寸均需保持可识别。

## 9. 明确禁用

- 旧黑白单色系统、旧系统 TabBar 或二者的运行时兼容分支。
- “断层海报”、高对比硬斜切、信号橙主动作、贴边硬页签、日期 Black 海报排版，以及为该方向保留的运行时兼容视图。
- 无限循环呼吸、宽度追逐底栏或以整屏透明命中层实现圆形主动作。
- 页面内直接写 RGB / Hex、第二套色板、运行时回退色或手工维护的重复 AppIcon 颜色。
- App 自绘毛玻璃、霓虹渐变、多层阴影和泛滥卡片；系统在 Widget 等表面提供的 Liquid Glass 不属于自绘效果。
- 多色统计图标、橙色火焰、勋章、积分和竞争排行榜。
- 伪书法、印章文字、樱花等与产品语义无关的装饰符号。
- 用颜色单独表达成功、漏签或今天。
