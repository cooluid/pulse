# 一日一印（Pulse）1.0 品牌与界面规范

冻结日期：2026-08-10
决策来源：用户将视觉方向收敛为“iOS 原生语言 + 纯黑单色”
适用范围：一日一印（Pulse）1.0 iPhone / iPad 产品界面、AppIcon 与商店素材
完整度：品牌名称、界面系统与正式 AppIcon 已冻结

## 0. 品牌名称

- 简体中文正式名称：一日一印。
- 英文及其他语言正式名称：Pulse。
- 简体中文设备、中文界面和中文商店素材统一使用“一日一印”，不得混用 Pulse 作为中文显示名称。
- Xcode target、Swift 类型、数据协议和 Bundle ID 保持稳定的工程名 Pulse，不因本地化品牌名称产生第二套技术身份。

## 1. 品牌立场

一日一印不是奖励型打卡游戏，而是一个可靠、私密、没有压力的每日记录工具。视觉记忆点来自“每天留下一枚清晰的记号”，不是积分、火焰、连续天数焦虑或庆祝动画。

关键词：原生、黑白、清晰、克制、可靠、私密。

## 2. 单一视觉系统

界面不维护自定义色板，统一消费 iOS 动态语义颜色：

- 普通页面：`systemBackground`，浅色为系统白，深色为系统纯黑。
- 分组容器：`secondarySystemBackground` 或 SwiftUI 原生 `GroupBox` / `Form` 外观。
- 主文字与签到动作：`primary`；浅色表现为纯黑，深色表现为纯白。
- 次级信息：`secondary`，仅用于日期、说明和补充层级。
- 分隔线：系统 `separator`。
- Tint：`primary`，不引入蓝、红、绿或暖灰品牌强调色。

不得复制系统颜色的固定 RGB 值。系统 API 是运行时唯一真源，负责适配浅色、深色、增加对比度和后续 iOS 外观变化。AppIcon 是系统外独立资产，只允许 `#000000`、`#FFFFFF` 和 Tinted 灰度源。

完成状态必须同时出现勾形、完成文案或可访问性标签，不能只通过明暗变化表达。

## 3. 字体与数字

- 中文、英文、数字和所有控件统一使用 Apple 系统字体与内置文本样式。
- 页面标题使用系统 Large Title / Title 层级；正文、说明和标签分别使用 Body / Subheadline / Caption。
- 统计数字使用系统字体、Semibold 和 `monospacedDigit`，不使用 serif、手写体或游戏化圆体。
- 不引入第三方字体，不产生字体授权、下载、回退和多语言维护链路。

## 4. 布局与组件

- 间距只使用 4 / 8 / 12 / 16 / 24 / 32 / 48。
- 页面水平边距：iPhone 20 pt；内容最大宽度沿用 iPad 自适应约束。
- 最小点击区域：44 × 44 pt。
- 背景为纯色，不使用渐变、毛玻璃或装饰光斑。
- 容器只使用 SwiftUI 原生 `GroupBox`、`Form`、`List`、`NavigationStack` 和 `TabView` 的系统外观。
- 默认使用留白与系统分隔线；不自绘卡片背景、边框、圆角或阴影。
- 阴影不用于常态层级。保存中的缩放反馈遵循 Reduce Motion。

## 5. 核心状态

### 待签到

- 今日主操作为纯黑 / 纯白系统语义圆形日印。
- 文案必须直接说明“今日签到”，不使用手指、火焰或礼物图标。
- 按下后只有持久化成功才进入完成态。

### 已签到

- 主操作保持单色，同时出现勾形和“今日已签到”。
- 显示实际写入时间。
- 不播放爆炸、彩屑或奖励动画。

### 历史

- 已签到：实心完成印 + 勾形。
- 今天待签到：`primary` 描边 + 日期。
- 漏签：系统次级分组面 + 日期。
- 未来 / 习惯开始前：降低对比度但仍可读。

## 6. AppIcon 合同

- 画布：1024 × 1024，不自行绘制系统圆角。
- Default 外观使用完整不透明底色；Dark 外观按 Apple 规范提供透明背景，让系统背景通过；Tinted 外观提供灰度图。
- Default：不透明纯白背景 + 纯黑 B2 图形。
- Dark：透明背景 + 纯白 B2 图形。
- Tinted：单一灰度遮罩，由系统应用用户选择的色调。
- 不含文字、数字、拟物阴影、渐变、3D、照片或水印。
- 核心图形在 29、40、60、180 和 1024 尺寸均需保持可识别。
- 已录用 B2“开放日环”。唯一正式图形真源为 `design/app-icon-source/open-day-ring-mask.png`，唯一色彩合同为 `design/app-icon-source/palette.json`，由 `scripts/build_app_icon.py` 确定性生成 Default / Dark / Tinted 资源。

## 7. 明确禁用

- 自定义暖纸、朱砂、茶绿、紫蓝渐变或霓虹科技感。
- 毛玻璃、泛滥的大圆角卡片和多层阴影。
- 多色统计图标、橙色火焰、勋章、积分和竞争排行榜。
- 伪书法、印章文字、樱花或其他装饰性“东方符号”。
- 用颜色单独表达成功、漏签或今天。
- 强制所有外观永久黑底；浅色与深色必须尊重系统外观选择。
- 页面内散落颜色、间距、圆角和动效常量。

## 8. 验收边界

界面代码通过构建、测试和模拟器视觉检查，只能证明工程实现符合本规范。AppIcon、商店截图和整体验收仍需要明确的视觉决策；自动化通过不能代替该决策。
