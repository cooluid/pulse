# 一日一印（Pulse）1.0 品牌与界面规范

冻结日期：2026-08-11
决策来源：C“脉冲场”今日页 × A“状态式底栏”主导航
适用范围：一日一印（Pulse）1.0 iPhone / iPad 产品界面、基础 Widget、AppIcon 与商店素材
完整度：品牌名称、颜色令牌、界面系统、主导航与正式 AppIcon 已冻结

## 0. 品牌名称

- 简体中文正式名称：一日一印。
- 英文及其他语言正式名称：Pulse。
- 简体中文设备、中文界面和中文商店素材统一使用“一日一印”，不得混用 Pulse 作为中文显示名称。
- Xcode target、Swift 类型、数据协议和 Bundle ID 保持稳定的工程名 Pulse，不产生第二套技术身份。

## 1. 品牌立场

一日一印是一个可靠、私密、没有压力的每日记录工具。视觉记忆点来自“草叶生长 + 日环留下印记”：草绿表达持续生长，脉冲同心场表达每天一次的轻量仪式，开放日环表达记录仍可继续。

关键词：草野、呼吸、清晰、克制、可靠、私密。

## 2. 唯一视觉真源

所有正式颜色只在 `design/brand-tokens.json` 定义一次。`scripts/build_brand_assets.py` 从该文件和唯一开放日环蒙版生成运行时 Color Set、AccentColor、AppIcon 三种外观、`PulseMark` 与 256 × 256 的 `PulseWidgetMark`；SwiftUI 只按语义名称消费生成资产。Widget 专用尺寸是同源派生输出，不是第二套手绘标记。

不得在 Swift、Asset Catalog、AppIcon 脚本或设计文档中复制另一份颜色值。新增或修改颜色必须先修改品牌令牌，再重新生成并执行：

```sh
python3 scripts/build_brand_assets.py
python3 scripts/build_brand_assets.py --check
```

正式语义角色：

- `background`：页面底色。
- `surface`：悬浮导航表面。
- `grass` / `grassForeground`：完成态、活跃导航与其前景。
- `action` / `actionForeground`：待签到主动作与其前景。
- `ink` / `secondary`：主次文字。
- `field`：脉冲环。
- `separator` / `shadow`：边界与悬浮导航层级。

浅色与深色必须分别使用令牌中明确的外观值；完成状态还必须同时出现勾形、完成文案或可访问性标签，不能只靠颜色表达。

## 3. 字体与数字

- 中文、英文、数字和控件统一使用 Apple 系统字体与 Dynamic Type。
- 104 pt 日期使用系统 Display 字形与轻字重；统计数字使用粗字重与 `monospacedDigit`，形成张弛对比。
- 页面标题、正文、说明和标签使用系统文本样式，不固定正文尺寸。
- 不引入第三方字体，不产生字体授权、下载、回退和多语言维护链路。

## 4. 今日页：C 脉冲场

- 年月、日号、星期、提示语、最近七天与签到动作必须属于同一个脉冲场，不拆成重复卡片。
- 最近七天只保留一条周轨迹，不得再出现第二份“最近 7 天”信息。
- 周轨迹位于签到状态之后、节奏摘要之前，不得与签到圆叠压，也不得沉到主导航之后破坏信息关系。
- 周轨迹的七个节点必须共用同一圆径和文字基线；今天待签到只用 `grass` 空心描边表达，已签到使用 `grass` 填充，禁止放大今天节点导致星期文字错位。
- 大号日期使用系统数字的自然字距并保留完整字形边界；不能用日期特判、负字距或额外补白修补两位数裁切。
- 待签到与完成态共用同一日期结构：年月与星期合并为顶端信息行，日号独占页面中轴，不重复显示“今天 / TODAY”，也不显示会改变结构的行动提示。
- 常规 Dynamic Type 下，待签到使用深草绿圆形主动作并在圆内显示“今日待签到”，圆外不重复解释未签到；成功持久化后切换为鲜草绿完成印，并只在圆内显示“实际时间 + 已签到”。
- 深浅色外观都必须保持 `action` 待执行态低于 `grass` 完成态的生长亮度；状态变化不能只替换文字。深色模式不得把待执行动作做得比完成印更亮。
- Accessibility Dynamic Type 下，主动作必须改为可纵向扩展的通栏胶囊，禁止把放大文字压进固定直径圆形。
- 完成态不显示“写入本机后完成”或圆外“已于某时写入本机”等重复说明。
- 同心环可以低频呼吸；主操作本身保持位置稳定。开启 Reduce Motion 或页面失活时停止呼吸。
- 本地写入短于 250 ms 时不闪现加载器；超过阈值后才显示保存进度。写入成功后先完成主印，再轻量更新周轨迹与连续天数，禁止所有信息在同一帧生硬跳变。
- 连续天数是次级节奏反馈，不使用火焰、积分、勋章或制造断签焦虑的奖励表达。
- 今日页在日号与签到主动作之间投影主承诺名称，作为“今天守住 / Today’s Commitment”的轻量只读语境；名称只读取正式 `Habit` 真源，不保存页面副本。可选“为什么重要”仍只在首次确认与设置编辑页出现。
- 主承诺提示不使用卡片、边框、阴影、材质、伪按钮或编辑入口，不进入签到圆内部，也不成为与日期竞争的第二个英雄标题。标签使用 `secondary`，名称使用 `ink` 与系统语义字号。
- 日期英雄区与签到主动作之间使用正式正间距，不再以负间距让签到圆覆盖英雄区。常规字号下长名称使用有限行数；Accessibility 字号允许自然换行和滚动。内容增长只能让后续内容顺序下移，不得重叠、缩字或按设备特判。
- 周轨迹之后只保留一行居中的连续状态：连续为零时使用“从今天开始”，大于零时使用完整的“连续 N 天”。它是无交互的次级结论，禁止左右分栏、边框、胶囊、卡片、阴影、材质背景和伪按钮命中区。
- iPad 常规字号使用正式双区构图：日期与主动作在左，周轨迹与节奏反馈在右；不得把 iPhone 单列整体居中后留下无意义的大面积空白。Accessibility 字号仍使用可滚动单列，保证阅读顺序稳定。

## 5. 主导航：A 状态式底栏

- 根界面只使用 `PulsePrimaryNavigation`，不保留系统 `TabView` 或旧 TabBar 的兼容分支。
- 今日项显示真实日期，并用副标题表达“待留下印记 / 今天已完成”。
- 记录项进入月历与统计。选中项使用 `grass` 填充，未选中项保持低强调表面。
- 选中项与未选中项宽度比例由 `PulseDesign` 的语义令牌统一定义；切换页面时宽度随选中状态交换，不按页面身份硬编码。
- Accessibility Dynamic Type 下取消宽度比例和副标题，两个入口改为等宽的“数字 + 页面名”结构；不得继续放大常规底栏造成底部裁切。
- Accessibility 可滚动内容必须使用底栏的真实测量高度作为末端清空区，滚动到末尾后最后一项完整位于底栏之上；不得为具体设备硬编码补白。
- 常规底栏的选中背景使用同一 `matchedGeometryEffect` 在两项之间移动；根内容同步做短距离淡入位移。开启 Reduce Motion 时两者均立即切换。
- 整个导航悬浮于页面底部、尊重安全区，所有交互目标不小于 44 × 44 pt。
- 两个根 `NavigationStack` 保持各自的页面导航状态；不可见根页不得响应触控或辅助功能焦点。
- 设置属于根页面之上的次级导航层；进入设置时隐藏主导航并释放底部安全区，返回根页面后恢复，禁止两层导航同时占据屏幕。

## 5A. 基础 Widget：A“裂环日签”

- Home Screen 小号与中号使用同一套紧凑四层语法：顶部左侧固定显示同源开放日环标记与放大的粗体“印记 / Imprint”，右侧以“日/月”显示日期，日号为主、月份与斜线为小号；其下是占满可用宽度的七日方块节律；中部以放大粗体显示当前主承诺名称；底部把粗体“待守护 / 已守护”与克制的单色 `☹︎ / ☺︎` 表情合并为一条状态带。Widget 配置正式关闭系统默认内容边距，Home Screen 改用顶部 4pt、水平 12pt、底部 4pt 的受控安全边距；Accessory 必须重新应用系统 `widgetContentMargins`。层间使用 4pt 最小节奏，方块在收紧轨道内居中，状态带锚定底边；禁止负边距或把内容直接顶进圆角蒙版。
- 顶部品牌区与 Lock Screen / Accessory 状态必须共用同一个派生自唯一真源的 `PulseWidgetMark` 外环，开放缺口始终可见。Accessory 待签到使用 `action` 裂环；完成后切换为 `grass` 裂环，并只在环内形成实心日印与勾形。Home Screen 底部状态带不再重复品牌环，避免同一小组件内出现两个竞争性的主标记。
- 日期使用系统粗体与等宽数字；`11/8` 中 `11` 是第一读，`/8` 为明确的小号辅助信息。必须以 `1 / 10 / 11 / 31` 日号和 `1 / 8 / 10 / 12` 月份验证完整字形边界，不使用日期位数特判、负字距或缩小整个布局补救裁切。
- 七日节律使用等分并占满可用宽度的方块轨道：已签到为大实心草绿方块，漏签为小实心次级方块，项目开始前为小空心方块，今天待签到为大空心强调方块。禁止胶囊刻度、基线或透明到消失的节点；新项目不能退化成孤立的“今天”方块。
- 底部状态带是 Home Screen 待签到态唯一明确的单向 AppIntent 入口，整条命中区域至少 44pt；待守护沿用浅色 `surface` 与单色 `☹︎`，已守护切换为 `grass` 背景、`grassForeground` 与单色 `☺︎`。表情使用文本呈现而非黄色彩色 emoji，必须跟随系统着色、深色与透明外观；完成态保持相同几何但静态不可撤销。
- 状态必须同时有背景形状、文字、表情或辅助功能标签，不能只换颜色。表情只做温和情绪辅助，不使用哭泣、庆祝、奖章或连续奖励语义；完成态保持静态，不在 Widget 中重演 App 内落印动画。
- Home Screen 按当前产品合同固定显示主承诺名称，不提供第二份展示偏好；名称只读取 `Habit` 真源，小号/中号最多两行并在超长时尾部截断，VoiceOver 仍读取完整名称。Lock Screen、StandBy 与 Always-On 不显示主承诺正文，任何 Widget 都不显示“为什么重要”。这一边界必须独立验收，不能把 Home Screen 的用户授权外推到更公开的系统表面。
- Lock Screen 圆形只呈现可签到的裂环日印；矩形以日期、短状态、七日方块和裂环组成紧凑阅读序列。两者使用系统 accessory 样式与 `widgetAccentable`，不得强行复制彩色品牌背景。
- Home Screen 全彩模式使用品牌浅/深语义 Color Set；系统着色或透明外观使用 `widgetRenderingMode` 分离主内容与强调内容。`containerBackground(for: .widget)` 保持可移除，由 iOS 26 的 Clear 外观替换为系统 Liquid Glass；旧系统和 Full Color 保留品牌背景。禁止把 `Color.clear` 或自绘模糊层伪装成可穿透壁纸的系统玻璃。
- 未设置或共享 store 未 `ready` 时显示简短“打开一日一印 / Open Pulse”和诚实设置说明，不显示待签到按钮或虚假空心态；读取失败使用独立不可用状态。
- WidgetKit 归档的位图必须使用专用小尺寸派生产物。禁止直接归档 1024 × 1024 的 AppIcon/品牌图，也禁止为规避平台限制重新手绘近似符号。
- Widget 不播放循环呼吸或 App 内落印仪式；点击单向签到后由系统刷新为静态完成态，Reduce Motion 与普通模式语义一致。
- 小号、中号、Accessory Circular、Accessory Rectangular 必须分别在系统 Widget Gallery 与真实表面验收；Preview、编译成功或资产尺寸检查不能代替运行证据。

## 6. 布局与组件

- 基础间距只使用 4 / 8 / 12 / 16 / 20 / 24 / 32。
- 页面水平边距：iPhone 20 pt；今日内容最大宽度 680 pt；历史内容最大宽度 760 pt；常规宽度双区内容最大宽度 1080 pt。
- 最小点击区域：44 × 44 pt。
- 今日与历史页面是无卡片的全屏脉冲场；根页面只有底部导航使用明确容器边界。设置页保留系统 `Form` / `List` 交互语义，但背景与 Tint 必须接入品牌系统。
- 阴影只服务于悬浮主导航和主操作层级，禁止把全屏场域包进圆角卡片。
- 所有视觉常量集中在 `PulseDesignSystem.swift`，页面不得散落重复的颜色、间距、圆角或动效常量。
- 脉冲场必须按 compact / regular 宽度使用各自的椭圆比例、环距、纵向位置与上下渐隐；装饰线不得侵入状态栏、穿过底栏或压低正文可读性。
- Accessibility 字号下页头设置入口改用系统齿轮图形并保留完整可访问性标签，避免放大文字与品牌名争抢宽度。

## 7. 历史与设置

- 已签到日期：草绿完成印 + 勾形。
- 今天待签到：Action 描边 + 日期。
- 漏签：叶面底色 + 次级文字。
- 未来 / 习惯开始前：降低对比度但保持可读。
- 已签到日期必须使用真实 Button 语义打开详情，不用手势伪装按钮。
- 月份切换同时提供 44 pt 的上一月 / 下一月可见按钮、左右滑动和辅助功能动作；三种入口必须汇入同一月份状态变更函数。当前月禁用下一月，切换方向必须与日历位移动效一致。
- iPad 历史页使用“月份与统计 / 月历”双区构图；统计分隔线只取内容固有高度，不得随宽屏父容器拉成长空框。
- 设置、时区、导入导出、删除确认继续使用系统标准控件，避免品牌化破坏平台可预期行为。
- 主题只提供跟随系统、浅色、深色三种模式并继续消费同一套语义 Color Set；不得复制页面或另建平行配色真源。
- 应用内语言只提供跟随系统、English、简体中文；切换后当前界面的日期、格式串、辅助功能标签和设置值必须同步更新，禁止中英混排残留。
- 设置中的单项说明进入对应控件副标题，分组说明作为卡片内部的说明行，不使用脱离圆角卡片的悬空 footer。
- `confirmationDialog` 必须挂在发起操作的按钮上，让系统箭头指向真实触发源；记录详情使用系统 Sheet 拖拽指示器关闭，不额外增加“完成”导航按钮。
- 设置入栈后根页不仅视觉隐藏，也必须从辅助功能树移除；返回后再恢复根内容和主导航。

## 8. AppIcon 合同

- 画布：1024 × 1024，不自行绘制系统圆角。
- 图形唯一真源：`design/app-icon-source/open-day-ring-mask.png`。
- 颜色唯一真源：`design/brand-tokens.json` 的 `icon` 与 `review` 角色。
- 生成器唯一入口：`scripts/build_brand_assets.py`；旧图标调色板与旧生成脚本不再存在。
- Default：品牌深草绿背景 + 白色开放日环。
- Dark：暗色背景 + 明亮草绿色开放日环。
- Tinted：单一灰度遮罩，由系统应用用户色调。
- 不含文字、数字、拟物阴影、渐变、3D、照片或水印。
- 核心图形在 29、40、60、180 和 1024 尺寸均需保持可识别。

## 9. 明确禁用

- 旧黑白单色系统、旧系统 TabBar 或二者的运行时兼容分支。
- 页面内直接写 RGB / Hex、第二套色板、运行时回退色或手工维护的重复 AppIcon 颜色。
- App 自绘毛玻璃、霓虹渐变、多层阴影和泛滥卡片；系统在 Widget 等表面提供的 Liquid Glass 不属于自绘效果。
- 多色统计图标、橙色火焰、勋章、积分和竞争排行榜。
- 伪书法、印章文字、樱花等与产品语义无关的装饰符号。
- 用颜色单独表达成功、漏签或今天。

## 10. 验收边界

构建、测试、资产一致性检查和模拟器截图共同证明工程实现符合本规范；它们不能代替最终产品视觉确认。真机触控、Widget 锁屏/Always-On、动态字体、VoiceOver、Reduce Motion、通知权限与发布素材仍需各自验收。
