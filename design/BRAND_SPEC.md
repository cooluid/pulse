# 一日一印（Pulse）1.0 品牌与界面规范

冻结日期：2026-08-10
决策来源：C“脉冲场”今日页 × A“状态式底栏”主导航
适用范围：一日一印（Pulse）1.0 iPhone / iPad 产品界面、AppIcon 与商店素材
完整度：品牌名称、颜色令牌、界面系统、主导航与正式 AppIcon 已冻结

## 0. 品牌名称

- 简体中文正式名称：一日一印。
- 英文及其他语言正式名称：Pulse。
- 简体中文设备、中文界面和中文商店素材统一使用“一日一印”，不得混用 Pulse 作为中文显示名称。
- Xcode target、Swift 类型、数据协议和 Bundle ID 保持稳定的工程名 Pulse，不产生第二套技术身份。

## 1. 品牌立场

一日一印是一个可靠、私密、没有压力的每日记录工具。视觉记忆点来自“草叶生长 + 日环留下印记”：草绿表达持续生长，脉冲同心场表达每天一次的轻量仪式，开放日环表达记录仍可继续。

关键词：草野、呼吸、清晰、克制、可靠、私密。

## 2. 唯一视觉真源

所有正式颜色只在 `design/brand-tokens.json` 定义一次。`scripts/build_brand_assets.py` 从该文件生成运行时 Color Set、AccentColor、AppIcon 三种外观和 `PulseMark`；SwiftUI 只按语义名称消费生成资产。

不得在 Swift、Asset Catalog、AppIcon 脚本或设计文档中复制另一份颜色值。新增或修改颜色必须先修改品牌令牌，再重新生成并执行：

```sh
python3 scripts/build_brand_assets.py
python3 scripts/build_brand_assets.py --check
```

正式语义角色：

- `background`：页面底色。
- `surface`：悬浮导航表面。
- `grass` / `grassForeground`：完成态、活跃导航与其前景。
- `action` / `actionForeground`：待签到主动作与其前景。
- `ink` / `secondary`：主次文字。
- `field`：脉冲环。
- `separator` / `shadow`：边界与悬浮导航层级。

浅色与深色必须分别使用令牌中明确的外观值；完成状态还必须同时出现勾形、完成文案或可访问性标签，不能只靠颜色表达。

## 3. 字体与数字

- 中文、英文、数字和控件统一使用 Apple 系统字体与 Dynamic Type。
- 104 pt 日期使用系统 Display 字形与轻字重；统计数字使用粗字重与 `monospacedDigit`，形成张弛对比。
- 页面标题、正文、说明和标签使用系统文本样式，不固定正文尺寸。
- 不引入第三方字体，不产生字体授权、下载、回退和多语言维护链路。

## 4. 今日页：C 脉冲场

- 年月、日号、星期、提示语、最近七天与签到动作必须属于同一个脉冲场，不拆成重复卡片。
- 最近七天只保留一条周轨迹，不得再出现第二份“最近 7 天”信息。
- 周轨迹位于签到状态之后、节奏胶囊之前，不得与签到圆叠压，也不得沉到主导航之后破坏信息关系。
- 周轨迹的七个节点必须共用同一圆径和文字基线；今天待签到只用 `grass` 空心描边表达，已签到使用 `grass` 填充，禁止放大今天节点导致星期文字错位。
- 大号日期使用系统数字的自然字距并保留完整字形边界；不能用日期特判、负字距或额外补白修补两位数裁切。
- 待签到与完成态共用同一日期结构：星期并入顶端 `TODAY / 年月 / 星期` 信息行，日号独占页面中轴，不显示会改变结构的行动提示。
- 常规 Dynamic Type 下，待签到使用深草绿圆形主动作并在圆内显示“今日待签到”，圆外不重复解释未签到；成功持久化后切换为鲜草绿完成印，并只在圆内显示“实际时间 + 已签到”。
- 深浅色外观都必须保持 `action` 待执行态低于 `grass` 完成态的生长亮度；状态变化不能只替换文字。深色模式不得把待执行动作做得比完成印更亮。
- Accessibility Dynamic Type 下，主动作必须改为可纵向扩展的通栏胶囊，禁止把放大文字压进固定直径圆形。
- 完成态不显示“写入本机后完成”或圆外“已于某时写入本机”等重复说明。
- 同心环可以低频呼吸；主操作本身保持位置稳定。开启 Reduce Motion 或页面失活时停止呼吸。
- 本地写入短于 250 ms 时不闪现加载器；超过阈值后才显示保存进度。写入成功后先完成主印，再轻量更新周轨迹与连续天数，禁止所有信息在同一帧生硬跳变。
- 连续天数是次级节奏反馈，不使用火焰、积分、勋章或制造断签焦虑的奖励表达。
- iPad 常规字号使用正式双区构图：日期与主动作在左，周轨迹与节奏反馈在右；不得把 iPhone 单列整体居中后留下无意义的大面积空白。Accessibility 字号仍使用可滚动单列，保证阅读顺序稳定。

## 5. 主导航：A 状态式底栏

- 根界面只使用 `PulsePrimaryNavigation`，不保留系统 `TabView` 或旧 TabBar 的兼容分支。
- 今日项显示真实日期，并用副标题表达“待留下印记 / 今天已完成”。
- 记录项进入月历与统计。选中项使用 `grass` 填充，未选中项保持低强调表面。
- 选中项与未选中项宽度比例由 `PulseDesign` 的语义令牌统一定义；切换页面时宽度随选中状态交换，不按页面身份硬编码。
- Accessibility Dynamic Type 下取消宽度比例和副标题，两个入口改为等宽的“数字 + 页面名”结构；不得继续放大常规底栏造成底部裁切。
- Accessibility 可滚动内容必须使用底栏的真实测量高度作为末端清空区，滚动到末尾后最后一项完整位于底栏之上；不得为具体设备硬编码补白。
- 常规底栏的选中背景使用同一 `matchedGeometryEffect` 在两项之间移动；根内容同步做短距离淡入位移。开启 Reduce Motion 时两者均立即切换。
- 整个导航悬浮于页面底部、尊重安全区，所有交互目标不小于 44 × 44 pt。
- 两个根 `NavigationStack` 保持各自的页面导航状态；不可见根页不得响应触控或辅助功能焦点。
- 设置属于根页面之上的次级导航层；进入设置时隐藏主导航并释放底部安全区，返回根页面后恢复，禁止两层导航同时占据屏幕。

## 6. 布局与组件

- 基础间距只使用 4 / 8 / 12 / 16 / 20 / 24 / 32。
- 页面水平边距：iPhone 20 pt；今日内容最大宽度 680 pt；历史内容最大宽度 760 pt；常规宽度双区内容最大宽度 1080 pt。
- 最小点击区域：44 × 44 pt。
- 今日与历史页面是无卡片的全屏脉冲场；只有节奏胶囊与底部导航使用明确边界。设置页保留系统 `Form` / `List` 交互语义，但背景与 Tint 必须接入品牌系统。
- 阴影只服务于悬浮主导航和主操作层级，禁止把全屏场域包进圆角卡片。
- 所有视觉常量集中在 `PulseDesignSystem.swift`，页面不得散落重复的颜色、间距、圆角或动效常量。
- 脉冲场必须按 compact / regular 宽度使用各自的椭圆比例、环距、纵向位置与底部渐隐；装饰线不得穿过底栏或压低正文可读性。
- Accessibility 字号下页头设置入口改用系统齿轮图形并保留完整可访问性标签，避免放大文字与品牌名争抢宽度。

## 7. 历史与设置

- 已签到日期：草绿完成印 + 勾形。
- 今天待签到：Action 描边 + 日期。
- 漏签：叶面底色 + 次级文字。
- 未来 / 习惯开始前：降低对比度但保持可读。
- 已签到日期必须使用真实 Button 语义打开详情，不用手势伪装按钮。
- 月份切换同时提供 44 pt 的上一月 / 下一月可见按钮、左右滑动和辅助功能动作；三种入口必须汇入同一月份状态变更函数。当前月禁用下一月，切换方向必须与日历位移动效一致。
- iPad 历史页使用“月份与统计 / 月历”双区构图；统计分隔线只取内容固有高度，不得随宽屏父容器拉成长空框。
- 设置、时区、导入导出、删除确认继续使用系统标准控件，避免品牌化破坏平台可预期行为。
- 设置中的单项说明进入对应控件副标题，分组说明作为卡片内部的说明行，不使用脱离圆角卡片的悬空 footer。
- `confirmationDialog` 必须挂在发起操作的按钮上，让系统箭头指向真实触发源；记录详情使用系统 Sheet 拖拽指示器关闭，不额外增加“完成”导航按钮。
- 设置入栈后根页不仅视觉隐藏，也必须从辅助功能树移除；返回后再恢复根内容和主导航。

## 8. AppIcon 合同

- 画布：1024 × 1024，不自行绘制系统圆角。
- 图形唯一真源：`design/app-icon-source/open-day-ring-mask.png`。
- 颜色唯一真源：`design/brand-tokens.json` 的 `icon` 与 `review` 角色。
- 生成器唯一入口：`scripts/build_brand_assets.py`；旧图标调色板与旧生成脚本不再存在。
- Default：品牌深草绿背景 + 白色开放日环。
- Dark：暗色背景 + 明亮草绿色开放日环。
- Tinted：单一灰度遮罩，由系统应用用户色调。
- 不含文字、数字、拟物阴影、渐变、3D、照片或水印。
- 核心图形在 29、40、60、180 和 1024 尺寸均需保持可识别。

## 9. 明确禁用

- 旧黑白单色系统、旧系统 TabBar 或二者的运行时兼容分支。
- 页面内直接写 RGB / Hex、第二套色板、运行时回退色或手工维护的重复 AppIcon 颜色。
- 毛玻璃、霓虹渐变、多层阴影和泛滥卡片。
- 多色统计图标、橙色火焰、勋章、积分和竞争排行榜。
- 伪书法、印章文字、樱花等与产品语义无关的装饰符号。
- 用颜色单独表达成功、漏签或今天。

## 10. 验收边界

构建、测试、资产一致性检查和模拟器截图共同证明工程实现符合本规范；它们不能代替最终产品视觉确认。真机触控、动态字体、Reduce Motion、通知权限与发布素材仍需各自验收。
