# 一日一印（Pulse）1.0 品牌与界面规范

冻结日期：2026-08-10  
决策来源：用户选定视觉方向 B“安静的每日仪式”  
适用范围：一日一印（Pulse）1.0 iPhone / iPad 产品界面、AppIcon 与商店素材
完整度：品牌名称、界面系统与正式 AppIcon 已冻结

## 0. 品牌名称

- 简体中文正式名称：一日一印。
- 英文及其他语言正式名称：Pulse。
- 简体中文设备、中文界面和中文商店素材统一使用“一日一印”，不得混用 Pulse 作为中文显示名称。
- Xcode target、Swift 类型、数据协议和 Bundle ID 保持稳定的工程名 Pulse，不因本地化品牌名称产生第二套技术身份。

## 1. 品牌立场

Pulse 不是奖励型打卡游戏，而是一个可靠、私密、没有压力的每日记录工具。视觉记忆点来自“每天留下一枚安静的记号”，不是积分、火焰、连续天数焦虑或庆祝动画。

关键词：留白、温和、仪式、可靠、私密。

## 2. 单一视觉系统

### 浅色模式

- 背景 / Warm Paper：`#F7F3E9`
- 主文字 / Warm Ink：`#302D28`
- 次级文字 / Warm Gray：`#6B655C`
- 主操作 / Vermilion：`#91372D`
- 完成辅助 / Tea：`#5B6E61`
- 分组面 / Soft Paper：`#EEE7D8`
- 分隔线：Warm Ink 12% 透明度

### 深色模式

- 背景 / Night Ink：`#1D1B18`
- 主文字 / Pale Paper：`#EEE7D8`
- 次级文字 / Pale Gray：`#B7AFA2`
- 主操作 / Light Vermilion：`#D87867`
- 完成辅助 / Light Tea：`#829487`
- 分组面 / Raised Ink：`#28251F`
- 分隔线：Pale Paper 14% 透明度

所有可执行颜色值由 Asset Catalog 统一保存，再由 `PulseDesign` 提供语义访问。业务页面不得新增十六进制颜色、RGB 常量或独立语义别名。

### 对比度基线

- Warm Ink / Warm Paper：12.37:1。
- Vermilion / Warm Paper：6.80:1。
- Warm Gray / Warm Paper：5.20:1；Warm Gray / Soft Paper：4.68:1。
- Pale Paper / Night Ink：13.96:1。
- Pale Gray / Night Ink：7.91:1；Pale Gray / Raised Ink：7.03:1。
- Light Tea / Night Ink：5.35:1。

完成状态不能只依赖茶绿色，必须同时出现勾形、完成文案或可访问性标签。

## 3. 字体与数字

- 正文、控件和设置：Apple 系统字体，完整支持中文、英文和动态字体。
- 今日页仪式标题：SwiftUI 原生 `serif` 设计变体；如果具体语言没有合适字形，由系统自然回退，不绑定私有字体名称。
- 日期和统计数字：原生 `serif` 设计变体、常规或中等字重；不使用游戏化圆体数字。
- 不引入第三方字体，不产生字体授权、下载、回退和多语言维护链路。

## 4. 布局与组件

- 间距只使用 4 / 8 / 12 / 16 / 24 / 32 / 48。
- 页面水平边距：iPhone 24 pt；内容最大宽度沿用 iPad 自适应约束。
- 最小点击区域：44 × 44 pt。
- 背景为纯色，不使用渐变、毛玻璃或装饰光斑。
- 卡片只用于确实需要分组的内容；默认使用留白和细分隔线组织信息。
- 圆角只保留在分组面和系统容器，不能让每个统计值各自成为悬浮卡片。
- 阴影不用于常态层级。保存中的缩放反馈遵循 Reduce Motion。

## 5. 核心状态

### 待签到

- 今日主操作为朱砂圆形日印。
- 文案必须直接说明“今日签到”，不使用手指、火焰或礼物图标。
- 按下后只有持久化成功才进入完成态。

### 已签到

- 主操作切换为茶绿完成印，同时出现勾形和“今日已签到”。
- 显示实际写入时间。
- 不播放爆炸、彩屑或奖励动画。

### 历史

- 已签到：实心完成印 + 勾形。
- 今天待签到：朱砂描边 + 日期。
- 漏签：中性浅面 + 日期。
- 未来 / 习惯开始前：降低对比度但仍可读。

## 6. AppIcon 合同

- 画布：1024 × 1024，不自行绘制系统圆角。
- Default 外观使用完整不透明底色；Dark 外观按 Apple 规范提供透明背景，让系统背景通过；Tinted 外观提供灰度图。
- 只允许暖纸、朱砂、温墨、茶绿这一套颜色关系。
- 不含文字、数字、拟物阴影、渐变、3D、照片或水印。
- 核心图形在 29、40、60、180 和 1024 尺寸均需保持可识别。
- 候选必须放在 `design/app-icon-candidates/`，在明确验收前不得写入 `Assets.xcassets/AppIcon.appiconset`。
- 已录用 B2“开放日环”。唯一正式图形真源为 `design/app-icon-source/open-day-ring-mask.png`，由 `scripts/build_app_icon.py` 确定性生成 Default / Dark / Tinted 资源；不得留下第二套正式图标或运行时兜底。

## 7. 明确禁用

- 紫蓝渐变与霓虹科技感。
- 毛玻璃、泛滥的大圆角卡片和多层阴影。
- 多色统计图标、橙色火焰、勋章、积分和竞争排行榜。
- 伪书法、印章文字、樱花或其他装饰性“东方符号”。
- 用颜色单独表达成功、漏签或今天。
- 页面内散落颜色、间距、圆角和动效常量。

## 8. 验收边界

界面代码通过构建、测试和模拟器视觉检查，只能证明工程实现符合本规范。AppIcon、商店截图和整体验收仍需要明确的视觉决策；自动化通过不能代替该决策。
