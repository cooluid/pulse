# 一日一印（Pulse）外观工程与验收边界

更新日期：2026-08-24
状态：Non-visual Contract

本文不描述 Pulse 应该长什么样，也不保存设计意图。全部外观由当前设计任务自由决定；任何现有实现都可直接重画。

## 1. 不建立设计权威

- 不建立参考板、反参考、风格宣言、页面映射或必须借鉴的视觉关系。
- 不把当前截图、SwiftUI、AppIcon、Widget 物件或任何图形题材写成后续兼容合同。
- 当次任务可以临时使用用户给出的参考；任务结束后，参考不自动成为项目门禁。
- 文档、测试、注释和交付叙事不得宣称某种审美是唯一正确方向。

## 2. 当前实现的工程入口

- 运行时外观由当前 SwiftUI、Asset Catalog 和 Renderer 直接实现。
- `design/brand-tokens.json` 与 `scripts/build_brand_assets.py` 是当前颜色和图标资产的生成入口，不是色彩或题材限制。设计需要时可以增加、删除、改名或重建令牌与资产。
- 用户可见文字只改 String Catalog；中文产品名为“一日一印”，英文名为“Pulse”。

## 3. 只保留非审美硬边界

- 签到、日期、统计、记事、照片、删除和恢复必须投影权威领域事实；视觉不能先于持久化宣称成功。
- 主题和构图不得改变用户已经拥有的功能，也不得伪造价格、权益或未交付能力。
- 状态必须具有可辨认的等价语义，不能只依赖颜色；VoiceOver、Dynamic Type、Reduce Motion、提高对比度和系统托管表面必须可用。
- 操作命中、系统权限、破坏性后果和系统控件行为必须真实可操作。如何构图不受本文限制。
- 照片、记事和主承诺进入哪些系统表面只由隐私与产品合同决定，不由装饰需要决定。

## 4. 测试不得管美术

- 自动化不得断言具体构图、颜色值、视觉令牌名称、字体、间距、圆角、阴影、图层数量、View 层级、SwiftUI 分支写法、动画材料、像素差或截图哈希。
- 可以测试：事实是否正确、操作是否完成、内容是否可读和可操作、状态是否有无障碍语义、Reduce Motion 是否停止非必要运动、系统动画是否满足平台硬上限。
- 渲染和截图可以作为人工评审附件，但不得作为审美 golden test。

## 5. 验收

构建和测试只证明工程与事实。外观是否好看、是否保留当前实现、是否需要重画，只由用户查看当前完整页面和真机体验后决定。
