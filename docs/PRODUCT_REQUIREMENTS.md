# 一日一印（Pulse）日签到产品需求

文档版本：3.3<br>
状态：Canonical Product Contract
适用范围：Pulse 1.1 本地优先、单用户、单一主承诺、可选每日记事与今日入镜、iPhone 伴侣型 Watch

## 1. 背景与目标

用户需要一个低干扰的日印工具：先用极少操作可靠记录“今天已经签到”，再自愿写下一条短记事或留下一张私人影像，让真实行动和真实时间共同形成长期档案。

MVP 的目标不是搭建任务平台，而是让以下闭环稳定成立：

1. 用户知道今天是否已经签到。
2. 用户能在两秒内完成签到。
3. 应用重启、快速连点和日期切换不会产生错误记录。
4. 用户能从历史记录理解自己的坚持情况。
5. 用户能在首次确认与设置中明确管理唯一主承诺，并在每日主流程中看见来自同一事实源的名称提示；可选说明不重复进入今日页。
6. 用户可在签到后拍一张“今日入镜”；相机、图片处理或存储失败不影响签到事实。
7. 签到与照片可独立查看、删除，并共同进入唯一加密归档。
8. 用户可在签到时或签到后补写、编辑、清空每日记事，且切换界面主题不会隐藏该能力。

## 2. 用户与使用场景

### 2.1 目标用户

- 使用自己的 iPhone 或 iPad 进行个人日签到。
- 不需要团队、审批或考勤证明。
- 希望记录长期保留，但首版接受本地数据边界。

### 2.2 核心场景

- 每天打开 App，确认状态并签到。
- 首次使用时确认唯一主承诺，并可选择记录一句备注。
- 在承诺变化时修改名称或说明，不影响既有签到事实。
- 所有用户都可从基础本地通知打开 App 签到；已购买增强且系统支持时，可从锁屏 Live Activity 或灵动岛入口打开 App 签到。
- 在 Home Screen Widget 查看当前主承诺、今日状态与七日节律，并直接完成单向签到；在 Lock Screen 只查看不泄露承诺正文的抽象状态。
- 查看本月哪些日期已签到或漏签。
- 查看当前连续天数、最长连续天数和累计签到数。
- 删除误操作产生的签到记录。
- 签到后自愿拍摄、重拍或跳过今日入镜，并可永久关闭邀请。
- 在记录页查看“签到 + 影像”“仅签到”或删除签到后保留的“仅影像”。
- 在任一界面主题下查看或编辑已签到日期的短记事；从 Widget / Live Activity 先签到后仍可补写。

## 3. 产品原则

- **单一主操作**：今日页只有一个签到主操作，不建立第二个业务提交入口。
- **事实优先**：只有保存成功的记录才算签到成功。
- **离线完整**：核心功能不依赖网络。
- **状态明确**：不能只靠颜色表达已签到、漏签或未来日期。
- **允许纠错**：这是个人记录工具，不以人为制造的不可撤销限制冒充数据可信度。
- **价值排序**：事实与交易必须直接；积分、社交和勋章不得先于记录可靠性。
- **影像独立**：照片是私人记忆，不是签到证明、考勤证据或成功前置条件。
- **主题等价**：界面主题不改变记事、照片、月历、漏签或统计能力。
- **数据主权**：拍摄、查看、删除和包含原图的完整加密备份不收费。

## 4. 信息架构

产品使用首次确认页、两个主页面；设置从今日页工具栏进入。

### 4.1 主承诺确认

- 首次创建或完整清除数据后，先确认唯一主承诺，再进入主界面。
- 默认名称可以一键继续，不要求选择模板；用户也可以直接填写自己的名称。
- “备注”为可选单句说明，不参与签到、统计或提醒判断。
- 首次确认不请求通知、评分、网络或其他系统权限。
- 未成功保存前不得进入主界面；保存失败保留输入并显示诚实错误。
- 从旧版本迁移或导入尚未确认的身份时，使用已有名称预填并要求确认，不重建项目或记录。

### 4.2 今日页

今日页必须让用户完成以下任务：

- 看清当前逻辑日期、当前“我的一件事”和今天是否已经签到。
- 未签到时可执行一次签到；保存中不能重复提交；失败时明确未保存并允许重试。
- 签到成功后可选拍摄、查看或管理今日照片。
- 签到前可以写每日记事并与签到原子保存；签到后可以查看、编辑或清空。
- 查看最近 7 个逻辑日和当前连续状态。
- 进入设置。

主承诺名称只读取正式 Habit，不复制身份状态；备注不进入今日页或系统表面。内容增长、Dynamic Type、iPhone/iPad 和横竖屏下不能重叠或裁切关键操作。

签到规则：

- 单击只签到；长按 0.45 秒表示“签到并拍照”。先提交权威签到，成功后才请求相机；拒绝、取消或拍摄失败不撤销签到。
- VoiceOver 提供“签到”和“签到并拍照”两条可达动作。
- 成功视觉与触觉只能在 Repository 提交之后出现；启动时读取到既有记录不能重播成功反馈。
- Reduce Motion 提供等价静态结果；动画不能阻止离开页面或延迟事实更新。
- 快速连续操作由 UI 与数据层共同保证同日幂等；前台跨日时刷新日期、状态与投影。

上述条款不规定日期、标题、签到控件、记事、照片入口、七日轨迹或导航如何构图。

### 4.3 记录页

记录页必须提供：

- 月份切换、月历/记事模式和当前月份统计。
- 已签到、漏签、今天、未来、项目开始前和有照片日期的可辨认语义。
- 有签到或照片的日期详情；照片按真实宽高比显示。
- 已签到日期的每日记事查看与编辑。
- 独立的删除签到、删除照片与导出原图操作；删除签到连带删除记事但保留独立照片，删除照片不改变签到与统计。
- 同日重新签到时重新关联仍保留的照片。
- 空白历史日期不能创建签到，即不支持补签。

今日与历史可以复用详情能力，也可以按当前设计重画。系统 Sheet、菜单、确认和 Dynamic Type 下必须可操作，但本文不规定其布局、detent、菜单位置、图标、颜色或视觉层级。

### 4.4 设置页

`P0`：

- 主承诺名称和可选备注的正式编辑入口。
- 触觉反馈开关。
- 当前签到时区展示。
- 清除全部数据。
- App 版本信息。

`P1`：

- 面向所有用户的每日基础提醒开关与提醒时间。
- 独立高阶权益页：购买状态、恢复购买与诚实错误；商品价格只读取 StoreKit，未购买不展示伪价格。已交付能力只读 `PulseEnhancementContract.currentCapabilities`，页面不得写入当前主题或签到事实。
- 独立 Widget 样式画廊：可以预览当前正式样式和内存中的待签到/完成状态，不得写入签到事实。收费样式必须明确权益状态并提供进入高级功能页的可达操作。
- 提醒时间。
- 一周起始日。
- 主题模式设置：跟随系统、浅色、深色。
- 界面主题：纸页手记是唯一免费与默认主题；静野、晴昼由同一个高级功能 StoreKit entitlement 解锁。三套主题中的签到、记事、照片、月历、漏签和统计能力必须等价。未验证权益时付费主题只能预览，不得启用、静默替换或保存伪解锁状态；权益撤销时统一切回纸页手记并说明结果。界面语言设置：跟随系统、English、简体中文；App 与 Widget 消费同一语言事实。
- 导出口令保护的 Pulse 加密备份；口令不保存且无法找回。
- 从 `.pulsebackup` 恢复数据；认证和完整校验后再由用户确认全量替换，不做隐式合并。
- 修改签到时区。
- 今日入镜邀请开关、媒体占用空间和“照片仅保存在本机与用户主动导出的加密归档”说明。
- 独立“帮助与反馈”分组：帮助中心、反馈与建议、隐私政策分别承担自助排障、主动联系和数据说明，不再用一个“产品支持”外链混合三种任务。反馈正文最多 2000 个 Swift `Character`，问题/建议分类、支持邮箱、版本信息和邮件模板只来自集中合同。页面只保留写信任务：分类、正文、可选截图、可选技术信息。发送时打开系统邮件编辑器，由用户检查、修改或取消。

破坏性确认必须来自实际触发操作并明确后果。

高阶权益只由 StoreKit 2 已验证交易派生，不持久化购买布尔值，也不进入 `CheckInRecord`、Repository、备份格式或 Widget 事实。商品展示名称与价格消费 App Store 返回值；`PulseEnhancementContract.currentCapabilities` 是已交付买断能力的唯一目录。新能力只有真正发布后才能加入目录和高阶权益页；加载失败、待处理、取消、无可恢复购买和验证失败均不得伪装为成功。

唯一 `PulseReminderDeliveryPolicy` 按“用户提醒意图 + 已验证权益 + 系统能力”选择主通道：只有用户关闭提醒时才为关闭；未购买、iOS / iPadOS 18–25，或 iOS 26 关闭 Live Activities 时，使用滚动 60 个日历日的一次性免费本地通知；已购买且 iOS / iPadOS 26 允许 Live Activities 时，先滚动安排系统接受的最多 7 个 standard Live Activity，再以本地通知覆盖同一 60 日窗口中未被 ActivityKit 接受的日期。任何逻辑日只能有一种触达，不能同日重复。

通知权限只在用户主动开启提醒时请求，用于免费基础提醒，以及付费 Live Activity 系统容量之外的长期连续性；首次启动不得直接弹出。用户拒绝通知时不能假装获得完整连续提醒，提醒开关保持关闭并明确说明授权要求。今天已过提醒时间时从明天开始，已签到日期不生成请求；启动、回到前台、任一系统入口签到、权益或提醒设置变化时刷新并先取消旧计划。系统调度容量和呈现由 iOS 裁决，产品文案不能承诺“到点一定出现”。

`PulseWidgetStyleAccessPolicy` 规定待落之处是唯一免费 Home Screen Widget 样式；星环、叠印、数影、手札、静场、来路、潮痕属于同一个高阶权益 entitlement。样式由 Home Screen WidgetKit 逐实例配置持有；Widget extension 验证权益，未知标识或未验证权益失败关闭。Lock Screen Widget 使用独立、无 Home Screen 样式参数的 kind。事实与系统行为见 [PULSE_RITUAL_CONTRACT.md](./PULSE_RITUAL_CONTRACT.md) 和 [WIDGET_SHARED_STORE_CONTRACT.md](./WIDGET_SHARED_STORE_CONTRACT.md)。

## 5. 功能范围

### 5.1 P0：核心 MVP

- 首次启动创建默认主承诺并要求用户确认；默认名称可一键继续。
- 单一主承诺命名、可选备注和后续编辑；修改不改写历史签到事实。
- 今日签到和持久化。
- 每条签到记录可选一条最多 120 字、4 行的每日记事；支持签到时写入、签到后补写/编辑/清空和跨主题访问。
- App 内可以提供有限签到反馈；只能在签到事实提交成功后进入完成表现。
- 当日唯一性与快速连点保护。
- 今日状态恢复和跨日刷新。
- 最近 7 天概览。
- 月历历史。
- 当前连续、最长连续和累计签到统计。
- 删除单条错误记录。
- 签到后拍摄/重拍/跳过今日入镜，签到和影像独立删除。
- 影像缩略图历史查看、相机邀请永久关闭与媒体空间展示。
- 清除全部数据。
- 深色模式、动态字体和 VoiceOver 基础支持。
- iPhone 与 iPad 自适应布局。
- 单元测试和核心 UI 测试。

### 5.2 P1：1.1 增强范围

- 免费基础提醒：所有用户均可使用本地通知；一次买断高阶权益在受支持的 iOS 26 系统上增加定时 standard Live Activity，可从 Lock Screen / Dynamic Island 直接签到。该系统表面没有用户样式选择，也不保存视觉偏好。当前产品名为“萤火日晕”。
- Pulse 加密备份 container v2 / payload v3 导出与全量恢复，包含签到、记事、媒体清单、原图与缩略图；备份/恢复永久属于免费数据主权能力。
- 签到时区设置。
- 一周起始日设置。
- 更完整的错误恢复和空状态说明。
- App 图标、启动体验和正式发布素材。
- 基础 Widget：Home Screen 小号/中号的待落之处面向所有用户；高阶权益解锁星环 / 叠印 / 数影 / 手札 / 静场 / 来路 / 潮痕。所有样式投影真实快照；未签到时提供唯一单向签到 AppIntent，完成后不可从 Widget 撤销。Lock Screen Widget 面向所有用户且不显示主承诺正文。App/Widget 只使用同一个 App Group store；App Group UserDefaults 仅保存界面语言、提醒开关与提醒时间，Home Screen 样式由系统逐实例配置，不保存签到状态或购买副本。

### 5.3 P2：后续候选，不属于 MVP 承诺

- 隐私锁；基础 Widget 已受控进入 1.0，后续仅评估不改变事实语义的高级 Widget / Control / Shortcuts，详细边界以 [WIDGET_SHARED_STORE_CONTRACT.md](./WIDGET_SHARED_STORE_CONTRACT.md) 为准；
- 签到成功后的其他跨系统反馈候选；
- 与签到事实分离的轻量回响和缺席说明，不形成补签；
- Apple Watch 的 28/90/365 日高级节律、印期、年轮和往年今日抽象回看，Shortcuts 和其他高级系统入口；
- 通过冲突原型门禁后的私密多设备同步；
- 将合格单人面貌照片本地对齐、网格形变和渐变融合的“岁月流影”，不做年龄、颜值或身份推断；
- 节律、印期、持续回响、长期档案等 Pulse Plus 能力；
- 微信提醒仅作为官方资格轨候选：主体、类目、模板、用户授权和真实发送全部通过后，才评估为本地提醒之外的可选通道。

后续候选的 GO / HOLD / NO-GO、免费与收费边界、数据合同和阶段门禁以 [PRODUCT_STRATEGY_2_X.md](./PRODUCT_STRATEGY_2_X.md) 为准；Widget、Live Activity、灵动岛、Apple Watch 和提醒通道语义以 [PULSE_RITUAL_CONTRACT.md](./PULSE_RITUAL_CONTRACT.md) 为准。多个并行项目继续 `HOLD`；补签、连续冻结、AI 面龄、全天常驻未签到灵动岛和非官方微信个人号自动化为 `NO-GO`。

### 5.4 明确不在 MVP 范围

- 登录注册。
- 社交、排行榜或好友监督。
- 订阅、积分商城和除高阶权益一次买断外的付费体系。
- 服务器防作弊。
- 团队考勤、审批或证明。
- 自动补签。
- 未定义冲突策略的多设备同步。

## 6. 业务规则引用

逻辑日、唯一性、连续天数、统计、删除和跨时区规则只以 [DOMAIN_CONTRACT.md](./DOMAIN_CONTRACT.md) 为准。

## 7. 非功能需求

### 7.1 性能

- 冷启动后首页应在本地数据加载完成时立即可交互。
- 用户点击签到到 UI 确认的目标时间小于 300 毫秒，不包含系统极端负载。
- 10 年每日一条记录的规模下，月历和统计仍应流畅。
- 统计计算不得阻塞主线程产生明显卡顿。

### 7.2 可靠性

- 数据保存失败不得显示成功。
- App 重启后状态与重启前一致。
- 同一个项目同一天最多存在一条有效记录。
- 主承诺身份修改不得改变项目 ID、起始日、时区或既有签到记录。
- “我的一件事”名称必须是规范化的 4...12 个 Swift `Character`；可选说明最多 160 个字符，具体规则以领域合同为准。
- 每日记事非法或超限时不得截断或写入；编辑不得改变签到时间、逻辑日或统计。
- 删除或清空数据应是显式操作，并在完成后刷新所有派生状态。

### 7.3 隐私

- P0/P1 不发送签到或照片到网络；App 与 Widget 只在受 iOS Data Protection 保护的本地 App Group 容器共享正式 store，Widget 不读取媒体。
- 用户主动创建的离设备备份使用独立口令和分条目 AES-256-GCM 保护，包含媒体；App 不保存或上传口令。
- Home Screen Widget 会持续显示用户确认的主承诺名称；Lock Screen、StandBy 与 Always-On 不显示主承诺正文，任何 Widget 都不显示可选备注。
- P0 不集成第三方分析或广告 SDK。
- 相机权限只在用户主动拍照时请求；除用户主动开启的通知权限外，不请求无关权限。
- App 内与商店资料使用同一公开隐私政策，设置页同时提供可达的产品支持入口。
- 反馈只在用户于系统邮件中主动发送后离开设备。诊断快照可展开查看并整组关闭，默认不铺开；可含版本、设备、日历、提醒、权益与本地数据规模，不得含“我的一件事”正文、签到时间或历史明细、记事正文、今日照片、备份、口令或设备 ID。截图只读取用户选中的一张，处理后附加。界面和邮件不列举未附带的数据。公开隐私政策说明主动邮件与可选技术信息，并与 App Store 隐私答案一致。
- 若未来加入云同步或分析，必须更新隐私说明并与本地数据策略区分。

### 7.4 无障碍与适配

- 支持深色模式。
- 主题与共享界面语言选择在重启后保持；清除全部数据后 App 与 Widget 内容共同恢复为跟随系统。
- 主操作最小点击区域为 44 × 44 pt。
- 支持默认至 Accessibility 最大动态字体尺寸；超大字体下允许纵向滚动。
- VoiceOver 能读出日期、签到状态、连续天数和按钮行为。
- 状态区分同时使用文本、图标或形状，不能只用颜色。

## 8. MVP 验收摘要

满足以下条件才可判定产品 MVP 完成：

- 核心规则的自动化测试全部通过。
- 真机上完成首次启动、签到、退出重进、跨日模拟、删除和清空流程。
- iPhone 与 iPad 均无阻断性布局问题。
- VoiceOver 和深色模式完成手工检查。
- 小号/中号与锁屏 Widget 的隐私、待签到/完成/不可用状态和单向签到完成真机检查；未打开 App 的首次状态不能被伪装成待签到。
- 已知数据丢失边界明确告知：未启用云同步时，未先导出完整加密归档就卸载 App 会丢失签到与照片。
- 详细矩阵见 [TEST_PLAN.md](./TEST_PLAN.md)。

## 9. 发布前产品决策门槛

以下任一项未决定，不能把工程完成等同于公开发布准备完成：

- iOS / iPadOS 18.0 的最低版本行为是否已在可用的最旧 18.x 运行时和真实设备覆盖范围中验证。
- 本地数据在卸载后丢失是否符合产品承诺。
- 本地优先、系统数据保护和加密备份恢复承诺是否仍成立；任何 iCloud 或远程处理变更都必须先更新隐私政策。
- 正式视觉、图标、商店素材和文案是否验收。
- 通知行为是否在真机上通过授权、拒绝和系统设置变更验证。
- iPhone 伴侣型 Apple Watch App、今日日印/七日脉冲 complication 与 Smart Stack 签到入口；iPhone 设置首页提供 Apple Watch 发现入口、配对/安装状态与波浪动态开关。Watch 只保存可重建快照和 durable command outbox，iPhone Repository 仍是唯一签到真源，iPhone `AppSettings` 是 Watch 外观偏好唯一真源。基础 Watch 查看与可靠签到免费。
