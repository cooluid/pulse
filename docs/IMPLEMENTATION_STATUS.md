# Pulse 实现与验收状态

更新时间：2026-08-10  
当前结论：核心实现与 C×A“草野脉冲”视觉工程完成；自动化工程门禁 GO，修订后最终产品视觉确认、真实设备新发布身份聚焦复验和公开发布仍为 NO-GO

## 已完成

- 删除 SwiftUI Hello World 模板和旧入口，不保留演示路径。
- 最低系统版本统一为 iOS / iPadOS 17.0。
- 建立版本化 SwiftData schema 和显式迁移计划。
- 建立单一主签到项目和 `habitID + logicalDay` 唯一记录键。
- 统一固定签到时区、逻辑日、跨日、连续天数和月历分类算法。
- 所有写入统一经 `SwiftDataCheckInRepository`，保存失败执行回滚。
- 今日签到、最近 7 天、当前连续、历史月历、最长连续和累计统计。
- 单条记录删除、全部数据清除和所有派生状态重算。
- 每日提醒权限、30 天滚动一次性通知和签到后取消当天提醒。
- 提醒时间以单一“午夜起分钟数”值存储，UI 与通知调度不读取设备当前日历。
- 签到时区、一周起始日和触觉反馈设置。
- 版本化 JSON 导出，以及校验完成后全量替换的 JSON 导入恢复。
- 中英文 String Catalog、深色模式、动态字体和基础 VoiceOver 标签。
- iPhone / iPad 自适应布局。
- 共享 Xcode scheme；仓库不再跟踪个人 `xcuserdata`。
- C“全屏脉冲场”今日/历史页面与 A“状态式底栏”作为 1.0 唯一视觉系统；根界面不再包含 `TabView` 或系统 TabBar 兼容分支。
- `design/brand-tokens.json` 是正式颜色唯一真源；生成器统一输出运行时 Color Set、AccentColor、品牌标记和 AppIcon。
- 今日页按确认原型实现 58 pt 品牌栏、`TODAY / 年月 / 星期` 顶端信息行、自然字距且位于中轴的 104 pt 日期区、签到状态下方的 244 pt 周节点轨迹、圆内时间完成文案、152 pt 开放日环、18/36 pt 晕圈、胶囊节奏条和选中/未选中 1.35:0.75 状态底栏；设置入栈时主导航统一隐藏，返回根页面后恢复。
- 移除旧黑白系统、卡片式今日/历史布局、重复“最近 7 天”、独立图标色板、旧图标生成脚本与未使用文案。
- “开放日环”几何继续录用；单一遮罩与草绿品牌合同确定性生成 Default / Dark / Tinted 资源。
