现稿差意思，不是颜色不够绿，而是五张都在说同一句话：「这里有一个大数字，下面有一排指标」。那是健康 App 和打卡工具的语言，不是一日一印。

  • 开放日环是印，不是进度环。缺口永远在，绝不画成百分比。
  • 完成靠形状闭合 + 勾，不只换色。
  • 现有七日快照就够本页六式；月历比分和连续天数不要做成主角。
  • 静场的残影必须从右下角印的圆心扩开，字在场上，印在原点。不能把脉冲场挪成角落装饰。

叠印

04 · LETTER

手札

手札是一张独立浅色笺纸，不叠第二张垫纸。左笺边与两条低对比书写纹建立文具身份；右上蜡封是今天，下沿是一串彼此独立、等大的邮戳日印，不画连接轨，也不重复日期。它是单张笺纸上的附言，不是摆正的叠印。漏签空心，已留下实心，今天开口；完成时今天这枚邮戳才闭合，蜡封同时打勾。

06 · PATH

来路

来路是走过来的一串独立足印，不是折线加点的健康图。过去六日由远到近、由小到大，不画连接线，也不在每个印迹旁重复日期；漏签空心，已留下实心。顶部只写一次由真实快照即时派生的「六日 · N 印」，不保存派生状态，也不做连续天数或比例。今天这一枚才是开口日环，环心保留今日日号。

这轮明确不走的路

4/7 分数、柱状「日强度」、GitHub 月点阵、连续 N 日奖杯、CSS 进度环、左右色块分栏、用七日同心圆去顶「年轮」这个名字。它们能让信息变多，但会把一日一印变成打卡看板。叠印是固定四页纸的材质物件，不承担七日计数；月度密度和连续天数若以后要做，也必须先是独立物件，而不是比分。
