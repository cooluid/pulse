# Widget 仪式物件

Home Screen 八式**产品清单**：待落之处、星环、叠印、数影、手札、静场、来路、潮痕。

本目录 HTML 是**探索草稿与对照**，不是像素合同。美术可随时重画；改画以代码与人工截图为准，不必先写长文档。

- 待落之处免费默认；其余收费（高阶权益）
- 工程渲染：`PulseWidgetUI/PulseWidgetRenderer.swift`
- 新产品实验：[widget-style-experiments](../widget-style-experiments/)

## 打开

```sh
cd docs/prototypes/widget-ritual-objects
python3 -m http.server 8766
```

打开 `http://127.0.0.1:8766/pulse-widget-ritual-objects.html`（示意尺寸 158² / 338×158）。

## 不要用它做什么

- 不要当成 INTERFACE GO 或商店图
- 不要把照片、备注、连续天数、4/7 分数当成 Widget 必填事实
- 不要把某次 HTML 外观锁成「唯一合法画法」
