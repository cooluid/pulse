# Pulse 产品路线

状态：Capability Roadmap
更新日期：2026-08-24

本文只记录能力顺序，不定义外观、设计意图、参考或画法。

## 当前发布基线

Pulse 1.1 关闭以下闭环：

- 单一主承诺、签到、记事、照片、历史和统计；
- 本地 App Group store、完整加密备份和恢复；
- 基础提醒、Widget、scheduled Live Activity 高级功能；
- iPhone 伴侣型 Watch、complication 和 Smart Stack；
- StoreKit 永久高级功能 entitlement；
- 中英文、隐私、无障碍和分发证据。

公开发布仍以 `IMPLEMENTATION_STATUS.md` 和 `TEST_PLAN.md` 的当前证据为准。

## 下一阶段

按以下顺序评估能力：

1. 关闭当前版本真实设备、系统表面、无障碍和分发门禁。
2. 观察核心签到、记事、照片、Widget 和 Watch 的实际使用可靠性。
3. 评估长期档案查询与用户主动生成的媒体输出。
4. 在冲突、删除、离线和隐私合同成立后评估多设备同步。
5. 评估 Shortcuts、Control 和其他系统入口。

## 长期候选

- 更长周期的只读节律与档案；
- 用户主动生成和导出的长期媒体结果；
- 私密多设备同步；
- 合法、可授权、可验证的额外提醒通道。

候选能力没有日期承诺，不能进入当前商品目录或界面占位。

## 商业边界

- 核心签到、历史、记事、照片、删除、导出、备份、恢复、基础提醒、基础 Widget 和基础 Watch 永久免费。
- 当前已购买高级功能继续由同一永久 entitlement 提供，不重复收费。
- 新付费能力必须已经交付，并提供不依赖锁住用户数据的独立价值。

具体外观由每次设计任务自由决定，不进入路线图。
