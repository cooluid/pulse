# Pulse 产品策略

状态：Product Capability Strategy
更新日期：2026-08-24

## 1. 定位

Pulse 服务一个长期任务：可靠记录每天是否完成“我的一件事”，并允许用户自愿留下短记事或私人照片。

- 单用户、单一主承诺、本地优先。
- 签到事实可靠性先于功能数量。
- 不扩张成团队考勤、社交排行、多习惯任务墙或服务器防作弊系统。
- 用户拥有自己的记录、照片、导出、删除和完整恢复能力。

## 2. 免费能力

以下能力不进入付费墙：

- 核心签到、历史、统计、删除和清除；
- 每日记事和今日照片的创建、查看、编辑、删除与原图导出；
- 完整加密备份和恢复；
- 基础提醒、基础 Widget 和基础 Watch 查看/签到；
- 隐私、无障碍和数据访问。

## 3. 当前高级功能

当前永久 entitlement 只控制已交付的可选增强：

- 静野与晴昼界面主题；
- 七个额外 Home Screen Widget 样式；
- 支持系统上的 scheduled Live Activity。

商品、价格和权益只读 StoreKit 与 `PulseEnhancementContract.currentCapabilities`。未交付能力不能预售；已购买用户不重复购买同一能力。

## 4. 顺序

1.1 基线：单一主承诺、签到、记事、照片、历史和统计；本地 App Group store 与完整加密备份；基础提醒、Widget、Watch；StoreKit 永久高级功能；中英文与分发证据。公开发布以 `IMPLEMENTATION_STATUS.md` 的当前证据为准。

接下来按这个顺序评估：

1. 关闭当前版本真实设备、系统表面、无障碍和分发门禁。
2. 观察核心签到、记事、照片、Widget 和 Watch 的实际使用可靠性。
3. 评估长期档案查询与用户主动生成的媒体输出。
4. 在冲突、删除、离线和隐私合同成立后评估多设备同步。
5. 评估 Shortcuts、Control 和其他系统入口。

长期候选没有日期承诺，不能进入当前商品目录或界面占位。

## 5. 明确不做

- 补签、连续冻结或篡改历史签到时间；
- 年龄、颜值、身份、健康或情绪推断；
- 未经用户主动操作上传照片、记事或面貌内容；
- 未定义冲突策略的云同步；
- 非官方个人账号自动发送提醒；
- 用订阅、积分、恐惧文案或数据锁定替代真实持续价值。

## 6. 决策门禁

新能力进入正式范围前必须回答：

1. 它解决哪个真实用户任务？
2. 权威数据是什么，失败和删除如何收敛？
3. 免费与收费边界是否损害数据主权或核心可靠性？
4. 自动化、真机、隐私、无障碍和分发证据是否分别成立？
5. 是否有真实使用证据，而不是只因为已经实现？
