# Pulse 2.x 产品策略

状态：Product Capability Strategy
更新日期：2026-08-24

本文只记录产品定位、能力边界和验证方法，不定义任何外观、设计意图或实现画法。

## 1. 定位

Pulse 服务一个长期任务：可靠记录每天是否完成“我的一件事”，并允许用户自愿留下短记事或私人照片。

- 单用户、单一主承诺、本地优先。
- 签到事实可靠性先于功能数量。
- 不扩张成团队考勤、社交排行、多习惯任务墙或服务器防作弊系统。
- 用户拥有自己的记录、照片、导出、删除和完整恢复能力。

## 2. 免费能力

以下能力不进入付费墙：

- 核心签到、历史、统计、删除和清除；
- 每日记事和今日照片的创建、查看、编辑、删除与原图导出；
- 完整加密备份和恢复；
- 基础提醒、基础 Widget 和基础 Watch 查看/签到；
- 隐私、无障碍和数据访问。

## 3. 当前高级功能

当前永久 entitlement 只控制已交付的可选增强：

- 静野与晴昼界面主题；
- 七个额外 Home Screen Widget 样式；
- 支持系统上的 scheduled Live Activity。

商品、价格和权益只读 StoreKit 与 `PulseEnhancementContract.currentCapabilities`。未交付能力不能预售；已购买用户不重复购买同一能力。

这些名称只表示产品目录，不约束外观。

## 4. 后续能力候选

后续候选只有在用户价值、数据合同和真实设备证据成立后才能进入发布范围：

- 更长期的节律和档案查询；
- 用户主动生成的长期媒体输出；
- 明确定义冲突与删除语义后的私密多设备同步；
- Shortcuts、Control 和其他系统入口；
- 符合官方资格、授权和真实发送能力的额外提醒通道。

候选能力不能改变既有签到事实，不能锁住用户数据，也不能靠不可用入口、演示内容或路线图文案冒充已交付。

## 5. 明确不做

- 补签、连续冻结或篡改历史签到时间；
- 年龄、颜值、身份、健康或情绪推断；
- 未经用户主动操作上传照片、记事或面貌内容；
- 未定义冲突策略的云同步；
- 非官方个人账号自动发送提醒；
- 用订阅、积分、恐惧文案或数据锁定替代真实持续价值。

## 6. 决策门禁

新能力进入正式范围前必须回答：

1. 它解决哪个真实用户任务？
2. 权威数据是什么，失败和删除如何收敛？
3. 免费与收费边界是否损害数据主权或核心可靠性？
4. 自动化、真机、隐私、无障碍和分发证据是否分别成立？
5. 是否有真实使用证据，而不是只因为已经实现？

外观只做当次人工验收，不进入产品策略门禁。
